The site is configured in `src/config/docs.config.ts`, a `DocsConfig` subclass. Gen renders `.stackra/site/docs.json`
from it; there is no hand-written `docs.json`.

| Field                                    | Controls                                                                                                            |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `name`, `description`, `theme`, `colors` | Site name, layout theme and brand colours                                                                           |
| `logo`, `favicon`                        | Brand assets, as paths under `src/assets` (`logo/light.svg`, `favicon.svg`)                                         |
| `navigation`                             | Tabs, groups, pages and `{ folder }` entries                                                                        |
| `navbar`, `footer`                       | Navbar links and button, footer socials and link columns                                                            |
| `apiReference`                           | Services whose API reference the site carries, from their committed manifests                                       |
| `raw`                                    | Every other Mintlify key, passed through: `appearance`, `styling`, `icons`, `search`, `seo`, `contextual`, `errors` |

Add `navbar`, `footer.socials` and `integrations` (under `raw`, analytics) once the public repository, social accounts
and analytics properties exist. The full schema is at [mintlify.com/docs.json](https://mintlify.com/docs.json).
