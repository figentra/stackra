# src/react

The `./react` entry of @stackra/icons (ADR 0294 decision 15): web renderers, one folder each,
`react/<name>/<name>.tsx` with its `__tests__/`. It imports `core/`, never `node/` or `native/`; `react` becomes an
optional peer with the first import.

The entry is exported once this folder holds a file. Its barrel is generated by `stackra gen`, never authored; until
gen ships (STA-339) the `./react` export names the entry's one public file (see `AGENTS.md`).
