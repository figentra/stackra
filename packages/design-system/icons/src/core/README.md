# src/core

Isomorphic code of @stackra/icons (ADR 0294 decision 15): services, drivers, errors, functions, schemas and blocks.
It imports `contracts/` and nothing host-specific; `node/`, `react/` and `native/` build on it.

`core/` and `config/` together are the `.` entry. Its barrel is generated by `stackra gen`, never authored; until gen
ships (STA-339) `.` names its one public file, the config class. When this folder gets its first public file, `.` has
two, so add the stand-in barrel that `AGENTS.md` describes.
