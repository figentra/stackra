# src/contracts

The `./contracts` entry: the leaf of @stackra/ui (ADR 0294 decision 15). It holds `ports/` (abstract classes
that extend `Port`), `enums/` and `types/`, and imports nothing else from the package; `core/` builds on it.

`./contracts` names the stand-in barrel `index.ts` (the shared enums, the provider types, the shared overlay and feedback contracts of wave 4 (open state, dismissal, placement, tone and icon), the shared collection contracts of wave 5 (items, selection, sort), the wave 5 data primitives (Table, List, PropertyList, Tabs, Accordion, CursorPagination, Breadcrumbs, EmptyState, ErrorState, PageSkeleton), the shared shell contracts of wave 6 (navigation item, landmark, bar slots, title block, layout breakpoint), the wave 6 shell and layout components (AppShell, Sidebar, NavigationList, AppHeader, PageHeader, Section, the two layouts, Screen, NavigationHeader, TabBar), the shared resource-index contracts of wave 7 (resource action, select-all-matching, resource query, filter kind, definition and value, number and date value props) and the props contracts of
Icon, Text, Heading, Button, IconButton, CloseButton, Link, Surface, Card, Separator, Chip, StatusBadge, Badge, Avatar, Spinner, Skeleton, SkeletonGroup, Checkbox, CheckboxGroup, ComboBox, Description, FieldError, Form, FormField, FormSection, InputGroup, Label, RadioGroup, SearchField, Select, Switch, TagGroup, TextArea and TextField, and the wave 4 Modal, Drawer, AlertDialog, Menu, ActionMenu, Popover, Tooltip, Alert, Toast, confirmation and progress contracts, and the wave 7 resource index: the query, filter, action and
select-all-matching contracts with DataTable, BulkActionBar, FilterBar, EntityPicker, NumberField, DateField and
DatePicker) until `stackra gen` writes the entry barrels (STA-339).
