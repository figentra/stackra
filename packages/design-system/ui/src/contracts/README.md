# src/contracts

The `./contracts` entry: the leaf of @stackra/ui (ADR 0294 decision 15). It holds `ports/` (abstract classes
that extend `Port`), `enums/` and `types/`, and imports nothing else from the package; `core/` builds on it.

The entry is exported once this folder holds a file. Its barrel is generated by `stackra gen`, never authored; until
gen ships (STA-339) the `./contracts` export names the entry's one public file (see `AGENTS.md`).
