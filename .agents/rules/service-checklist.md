# Service checklist

A service is `services/<name>`, `@figentra/service-<name>`, tag `tier:service`, entry `src/main.ts`, which bootstraps the root module the member
declares in `package.json` (ADR 0126; owner G2). Its code is organised by kind folders: `models/`, `actions/`, `queries/`, `services/`,
`events/`, `listeners/`, `workflows/`, `policies/`, `permissions/`, `settings/`, `contracts/`, and `raw/` only for `@Controller` raw endpoints
(ADR 0130). There is no `controllers/`, `dtos/`, `repositories/` or `presentation/` folder. Eight non-negotiables:

1. **Placement and kind folders.** The placement test passes (`module-boundary`). Code sits in the kind folders above. Imports across folders use
   `#` aliases (ADR 0233).
2. **Two-layer tenant isolation** once a tenant-owned table exists (see `tenancy`).
3. **Event-first.** Cross-service communication is a versioned event unless an authoritative decision is needed now (ADR 0141, 0142).
4. **One gateway.** No service sets CORS or exposes a public surface of its own. The gateway is generated by `stackra gen` (ADR 0237, wave 2
   part 4); services hold no Encore files.
5. **Idempotency on every write** (`http-conventions`, ADR 0136).
6. **Required files:** `README.md`, `AGENTS.md` with a `## PII` table (even if "none"), `CHANGELOG.md`, `LICENSE`,
   `isolation.test.ts` once a scoped table exists.
7. **Secrets:** declared by name only (`secret('STRIPE_SECRET_KEY')`). The production value comes from Infisical through runway (ADR 0173).
   Tests need none.
8. **Definition of done:** code, `pnpm verify` green, the service's own tests green, docs current, reviewer sign-off. `pnpm verify` never
   starts a service, so a typecheck is not proof it runs.

Enforcement: `tools/scripts/validate-repository.mjs` (member shape, `checkService`, tier tag); items 2-5 and 8 are reviewer-checked
(planned checks). Docs: `apps/docs/src/standards/services.mdx`.
