# Plan: a typed queues registry (`#stackra/queues`)

**Spec**: [spec.md](./spec.md) · **Linear**: STA-1723 · **Tier**: feature

## Approach

1. Extract the queue collection that `emitEncoreQueues` does inline into `jobQueues(manifest)` (job actions' queues,
   `default` for a job without one) and use it in both emitters.
2. New `emitQueues(ir, manifest)` in `packages/developer/gen/src/core/functions/emit-queues.function.ts`: returns
   undefined for a non-service or a service without a job action; else `.stackra/gen/queues.ts` with the generated header,
   `import { queues } from "@stackra/queue";` and `export const Queues = queues([...sorted, "default"] as const);`
   (`default` once).
3. Call it from `generateMember` (the optional `.stackra/gen` files).
4. Reader: beside `i18nKey`, a `queueName(node)` that reads `Queues.<Name>` whose `Queues` is imported from
   `#stackra/queues` as the snake_case name; `constant()`'s PropertyAccessExpression case tries it first.
5. README: the generated-files table gains `#stackra/queues`, with the digit-part limit.
