# The box agent contract (shared by infra-testbed and `stackra testbed`)

`testbed-agent` is a POSIX sh script installed on every box at `/usr/local/bin/testbed-agent` by the AMI. The Mac
side (`stackra testbed`) only ever calls these verbs over SSH as `ubuntu`. Output is one line unless stated.

| Verb                                                                              | Prints / does                                                                                                                                                                                                                                                                                                                                                                         | Exit          |
| --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------- |
| `testbed-agent slot <heavy\|light>`                                               | `free`, or `busy <who>`                                                                                                                                                                                                                                                                                                                                                               | 0             |
| `testbed-agent health`                                                            | `healthy`, or `unhealthy: <reason>` (disk, memory, docker, postgres, infisical, draining)                                                                                                                                                                                                                                                                                             | 0 / 1         |
| `testbed-agent status`                                                            | `heavy <free\|busy who>, light <free\|busy who> \| disk <data%>/<root%> \| <healthy\|unhealthy: r> \| ami <id> <age>d \| load <1m>`                                                                                                                                                                                                                                                   | 0             |
| `testbed-agent job prepare <id> <project>`                                        | creates `/data/jobs/<id>/<project>` (reflink clone of `/data/seed/<project>` when present), prints that path                                                                                                                                                                                                                                                                          | 0             |
| `testbed-agent job run <id> <heavy\|light> <who> <project> [--postgres] -- <cmd>` | health check (refuses with exit 75 and `unhealthy: …`), takes the slot lock (exit 73 `busy <who>`), scale-in protection on, `pnpm fetch` into the shared store (one writer), Infisical token, fresh container, streams output, then always cleans up (containers and network by label `stackra.testbed.job=<id>`, seed refresh, `rm -rf /data/jobs/<id>`, protection off, lock freed) | the command's |
| `testbed-agent job stop <heavy\|light>`                                           | stops the slot's running job (container and labelled children); prints `stopped <who>` or `free`                                                                                                                                                                                                                                                                                      | 0             |
| `testbed-agent guard`                                                             | the disk guard pass (timer, every 5 min): clean at 70%, drain at 85%                                                                                                                                                                                                                                                                                                                  | 0             |
| `testbed-agent idle`                                                              | the idle pass (timer): terminate self and decrement desired when idle 60 min and the group is above its minimum                                                                                                                                                                                                                                                                       | 0             |

Exit codes reserved: 73 slot busy, 75 box unhealthy (caller picks another box), 124 job timeout (3 h).

- The workspace is `/data/jobs/<id>/<project>`; the Mac rsyncs into it after `job prepare`.
- Secrets: `/etc/testbed/grants.json` (written from the plan at boot, no value) maps a project name to a list of
  `{ projectId, environment, path }`; projects absent from it run with no Infisical token. The identity id is in
  `/etc/testbed/identity` (an id, not a secret).
- Instance tags: `stackra:testbed` = `heavy` | `light`; `Name` = `stackra-testbed-<group>`.
- Defaults the CLI also knows: AWS profile `academorix`, region `eu-west-1`, SSH user `ubuntu`, security group
  `stackra-testbed`, key file `~/.ssh/academorix-ci.pem` (key pair `academorix-ci` imported into eu-west-1).
