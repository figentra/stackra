Add `@stackra/navigation` (absorbs `@stackra/router`): the `Route`, `Layout` and `Menu({ kind })` kinds with typed
`RouteContext`, `MetaContext` and `RouteProps`, `routeRef` and the route table, `ChromeConfig`, the React Router 7
adapters (`toRoot`, `toLayout`, `toRoute`, `routeAdapter`, `routeContext`), router-aware `Link`, `NavLink` and hooks
in the visitor's locale mount, the root error boundary, the React Navigation adapters (`toScreen`, `useLayoutLoader`,
`ContextMenu`) and `runLoader` for tests.
