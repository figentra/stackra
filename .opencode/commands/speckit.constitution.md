## Stackra: the constitution is generated

`.specify/memory/constitution.md` is generated by `pnpm agents:sync` from the laws in
`apps/docs/src/docs/constitution/*.mdx`. Do not edit it here, and do not write it from this command.

- To read the current laws, open `.specify/memory/constitution.md` or the `.mdx` pages.
- To change a law, follow the constitution's "Amending a law" steps: an ADR, the owner's acceptance, an edit to the
  `.mdx` page, then `pnpm agents:sync`. `pnpm agents:check` fails when the generated file drifts.

Tell the user this and stop. If the input asks for feature work, say it belongs in `/speckit-specify` instead.
