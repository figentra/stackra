An Expo SDK 57 app: expo-router native tabs (Liquid Glass on iOS 26, Material on Android), HeroUI Native and
Uniwind (Tailwind v4 for React Native).

| Command          | Does                                             |
| ---------------- | ------------------------------------------------ |
| `pnpm dev`       | `expo start` (Metro)                             |
| `pnpm ios`       | Build and run in the iOS simulator (needs Xcode) |
| `pnpm android`   | Build and run on Android                         |
| `pnpm typecheck` | `tsc --noEmit`                                   |
| `pnpm doctor`    | `expo install --check` — SDK-compatible versions |
| `pnpm lint`      | oxlint                                           |
| `pnpm format`    | oxfmt                                            |

## Structure

| Path                           | Holds                                                       |
| ------------------------------ | ----------------------------------------------------------- |
| `src/app/`                     | Routes (expo-router); `(tabs)/` holds one stack per tab     |
| `src/components/ui/`           | Shared UI: `Screen`, `Glass` (Liquid Glass with a fallback) |
| `src/components/tab-stack.tsx` | Header options every tab stack shares                       |
| `src/global.css`               | Tailwind + Uniwind + HeroUI Native styles                   |
| `app.json`, `eas.json`         | Expo and EAS build config                                   |

`ios/` and `android/` are generated by `expo run:*` / `expo prebuild` and are not committed.
