# `.specify/`

The [GitHub spec-kit](https://github.com/github/spec-kit) install, written by the pinned `specify` CLI (`mise.toml`,
[ADR 0067](../apps/docs/src/adr/0067-spec-kit-is-the-sdlc.mdx),
[ADR 0121](../apps/docs/src/adr/0121-sdlc-tooling-roles-and-linear.mdx) D15). Nothing here is hand-written: it is
generated and committed so every clone and CI see the same spec engine.

| Path                                       | Holds                                                                                                 |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| `init-options.json`                        | the init settings: Claude and OpenCode integrations, `feature_numbering: linear-key`, `speckit_version` |
| `integration.json`, `integrations/`        | which integrations are installed and the files each one rendered                                      |
| `memory/constitution.md`                   | the constitution the plan checks against, generated by `pnpm agents:sync` from the docs laws           |
| `templates/`                               | spec-kit's core templates (the Stackra preset overrides spec, plan and tasks)                         |
| `presets/stackra/`                         | the installed Stackra preset; its source is `.agents/speckit/presets/stackra`                         |
| `scripts/bash/`                            | the scripts the commands call; `setup-plan.sh` runs the spec gate first                              |
| `workflows/`                               | the bundled `speckit` workflow, kept disabled                                                         |
| `.gitignore`                               | ignores `feature.json`, the per-checkout pointer to the current spec folder                           |

## Rules

- Do not edit files here. Change the preset in `.agents/speckit/presets/stackra` and run `pnpm speckit:sync`; the
  constitution comes from `pnpm agents:sync`.
- Upgrade spec-kit only in a dedicated PR: bump `mise.toml` and `speckit_version` together, run `pnpm speckit:sync`,
  then `pnpm validate`. The `spec-gate ci` tripwire fails when an upgrade breaks the Stackra wrap.
- JSON here stays strict JSON (its scripts read it with jq), and oxfmt skips the folder.
- Specs are not written here: they live in [`.agents/specs`](../.agents/specs).

Docs: [spec lifecycle](../apps/docs/src/agents/spec-lifecycle.mdx).
