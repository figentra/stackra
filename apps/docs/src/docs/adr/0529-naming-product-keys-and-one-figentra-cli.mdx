## Context

Products were named three ways at once: a bare word in one place, `figentra-<word>` in another, an `f-` prefix in a
third. Each product was also starting to ship its own binary. Flow's package folder still carried the retired
`figentra-flow` name after the CLI became `fflow`. Pulumi requires its own file names, which collide with our casing
rules.

## Decision

1. **A product key is one short lowercase word** (for example `flow`). The repository, folders, runway
   `product.key`, the Linear project and the secret scopes use the bare key.
2. **`figentra-<key>` only where a name is global**: the Encore app, the AWS account, Cloudflare Worker and Pages
   names, GCP projects. npm packages stay `@figentra/<key>-…` ([0083](/adr/0083-npm-scopes-and-cli-names)). There is
   no `f-` prefix anywhere except the `fflow` CLI.
3. **One `figentra` CLI that products plug into.** `figentra` is the host: its core commands plus a command group
   from every installed product. A product's package declares its group in package.json
   (`"figentra": { "commands": "./cli" }`); the host discovers groups from the dependencies, never from a hard-coded
   list, through `@stackra/console`'s command registration. `figentra --help` lists the core commands and every group
   present.
4. **Binaries that stay.** `stackra` (the public framework) and `fflow` (Flow, sold standalone) keep their own
   binaries because they are used outside Figentra. Runway folds into the framework command: `stackra runway …` runs
   every Runway command, and the `runway` binary stays only as an alias, with a deprecation notice, for a transition
   period (one minor release by default, a setting), then is removed (STA-2214). When Flow is installed next to
   `figentra`, it also registers as `figentra flow`. No product ships another binary.
5. **Flow's package folder is `packages/flow`** (package `@figentra-oss/flow`, CLI `fflow`). `figentra-flow`,
   `figentra_flow` and `FIGENTRA_FLOW` are banned in every case, except real external names that cannot change (a
   GitHub App slug, an identity already issued), which are listed in the check's allow list.
6. **Pulumi files keep Pulumi's names** (`Pulumi.yaml`, `Pulumi.<stack>.yaml`) because the CLI requires them. Our own
   files beside them follow [0231](/adr/0231-naming-and-casing-standard).

## Consequences

- Product CLIs become groups under `figentra`; per-product binaries are retired as each product moves.
- Renames of existing folders and scopes are done repository by repository with each repository's lane.
- The ban needs an allow list, kept short and reviewed.
