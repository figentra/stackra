What each GitHub environment of the repository runs now.

```bash
stackra runway status [environment] [--json]
```

| Argument or option | Kind     | Meaning                                              |
| ------------------ | -------- | ---------------------------------------------------- |
| `environment`      | argument | One runway or GitHub environment; default every one. |

## What it does

Read-only `gh api` GETs of GitHub's deployment records, for the runway environments plus
`providers.github.environments`. It changes nothing.

## What it prints

One row per environment: the commit, when it was deployed, and the latest state (`none` when nothing has deployed
there). Each row is the `--json` data.

## Exit codes

| Code | Means                            |
| ---- | -------------------------------- |
| 0    | Printed.                         |
| 1    | `gh` failed or is not signed in. |
| 2    | Usage error.                     |

## Where it runs

With the person's own `gh` login, or a job's token.

## Examples

```bash
stackra runway status
stackra runway status production --json
```
