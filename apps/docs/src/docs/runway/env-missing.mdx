Fails a deploy whose sops scope lacks a secret the deploy syncs, before anything is decrypted.

```bash
stackra runway env missing <environment> [--dir <dir>]
```

| Argument or option | Kind     | Meaning                                                        |
| ------------------ | -------- | -------------------------------------------------------------- |
| `environment`      | argument | dev, preview, staging or production.                           |
| `--dir`            | option   | The folder holding the scope's ciphertext; default `.secrets`. |

## What it does

Takes the names a deploy of the environment syncs: each member's runway `secrets`, the `secret` and `config` names its
committed manifest declares for that environment, and the generated gateway's. It compares them with the file names of
the scope's ciphertext (`<dir>/products/<project>/<env>/<NAME>.enc.yaml`). It decrypts nothing and reads no value.

A name only code declares, with `required: false` everywhere (an optional `@Secret` or config field), may be absent:
`runway secrets sync` writes it as an empty placeholder, so Encore still provisions the service. Any other name the
scope lacks fails the run. A member no runtime takes secrets from is not checked.

## What it prints

One error per required name the scope lacks, and one warning per optional one, each with its member folder; or that the
scope holds every required secret.

## Exit codes

| Code | Means                                                                           |
| ---- | ------------------------------------------------------------------------------- |
| 0    | The scope holds every required name; optional absent names only warn.           |
| 1    | A required name is missing, outside a proved CI job, or the ciphertext is gone. |

## Where it runs

Only in a CI job its GitHub OIDC token proves. The secrets-decrypt action runs it before the decrypt when its
`check-environment` input names the environment.

## Examples

```bash
stackra runway env missing staging --dir .secrets
```

```yaml
- uses: stackra-inc/stackra/.github/actions/secrets-decrypt@<sha>
  with:
    scope: products/acme/staging
    check-environment: staging
```
