Writes an environment's member secrets into the runtimes, from the job's environment.

```bash
stackra runway secrets sync <environment> [--dry-run]
```

| Argument or option | Kind     | Meaning                                                             |
| ------------------ | -------- | ------------------------------------------------------------------- |
| `environment`      | argument | dev, preview, staging or production.                                |
| `--dry-run`        | option   | Print the secret names and their writers; read and write nothing.   |
| `--from-env`       | option   | Deprecated and ignored: the job's environment is always the source. |

## What it does

Reads each member's declared secret names, takes their values from the job's environment (where
`.github/actions/secrets-decrypt` put the product's sops scope), and writes them into the runtimes. Values stay in
memory; only names are printed.

## What it prints

Each name and where it was written. A declared name the job lacks fails the run before anything changes.

## Exit codes

| Code | Means                                                                           |
| ---- | ------------------------------------------------------------------------------- |
| 0    | Synced, or printed for a dry run.                                               |
| 1    | A declared name is missing, a writer failed, or the run is not a proved CI job. |
| 2    | Usage error.                                                                    |

## Where it runs

A real sync runs only in a GitHub Actions job its OIDC token proves. `--dry-run` runs anywhere. Also spelt
`stackra runway env sync`.

## Examples

```bash
stackra runway secrets sync staging --dry-run
```
