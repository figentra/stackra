Decrypts one figentra/secrets scope into the running job's environment, masked.

```bash
stackra runway secrets decrypt --scope <scope> [--dir <dir>] [--names A,B]
```

| Argument or option | Kind   | Meaning                                                                                             |
| ------------------ | ------ | --------------------------------------------------------------------------------------------------- |
| `--scope`          | option | The scope: `agents`, `ci/<build\|deploy\|production\|flow>[/folder]` or `products/<product>/<env>`. |
| `--dir`            | option | The folder holding `<scope>/<NAME>.enc.yaml`; default `.secrets`.                                   |
| `--names`          | option | Only these names, comma-separated; default the whole scope.                                         |

## What it does

Decrypts the ciphertext the shared `secrets-decrypt` action downloaded, with the job's own Cloud KMS identity, masks
each value and exports it into the job's `GITHUB_ENV` for the steps after it.

## What it prints

The scope, how many names were exported, and their names. Never a value.

## Exit codes

| Code | Means                                                                                                |
| ---- | ---------------------------------------------------------------------------------------------------- |
| 0    | Exported.                                                                                            |
| 1    | No `--scope`, no `GITHUB_ENV`, or the scope cannot be decrypted (the job's identity holds no grant). |

## Where it runs

Only in a GitHub Actions job: it refuses where there is no `GITHUB_ENV`. Which job may decrypt a scope is Cloud KMS's,
pinned per repository, environment and workflow by figentra/infra. Workflows call it through
`figentra/stackra/.github/actions/secrets-decrypt`.

## Examples

```bash
stackra runway secrets decrypt --scope ci/build/registry --names STACKRA_REGISTRY_TOKEN
```
