Checks every runway file against its schema, the placement and the drivers.

```bash
stackra runway validate [--json]
```

## What it does

Reads the root runway and each member's runway (under `apps/`, `services/` and `workers/`), and checks each against
its kind's schema, then the root's placement, its destinations and target blocks against the drivers, and each
service's requirements. It changes nothing. `stackra validate --repository` runs the same checks.

For a service whose generated `stackra.manifest.json` binds the action stores (`actions.IdempotencyStore`,
`actions.RateLimitStore`), every deployed environment (`preview`, `staging`, `production`) must set
`config.actions.stores.idempotency` and `config.actions.stores.rateLimit` to `postgres` or `valkey`, in the member or
in the root's `defaults.service.config`. The default `memory` store forgets every Idempotency-Key on a restart, so a
retried write runs twice, and keeps one rate-limit bucket set per instance. The driver must also be one the service's
packages provide: `postgres` needs `@stackra/database`. The app refuses the same thing at boot: gen writes these
values into the service's `#stackra/runway-config`, and the generated Encore app reads the environment from Encore
through the one environment reader. `config.actions.stores.environment` is not a value runway can set: it comes from
`STACKRA_ENVIRONMENT` in the runtime only, and setting it is a finding.

## What it prints

One line per finding, `<file>: <path>: <message>`. A deprecated field that is still set (for example a Mintlify block,
or `providers.aws.region`) prints a warning naming what replaces it, and still passes for one release.

## Exit codes

| Code | Means                                         |
| ---- | --------------------------------------------- |
| 0    | Every file is valid; warnings may be printed. |
| 1    | At least one finding.                         |
| 2    | Usage error.                                  |

## Where it runs

Anywhere, with no login. CI runs it in the Quality Gate.

## Examples

```bash
stackra runway validate
stackra runway validate --json
```
