Warns on names in an environment's sops scope that no code declares.

```bash
stackra runway env orphans <environment> [--dir <dir>]
```

| Argument or option | Kind     | Meaning                                                        |
| ------------------ | -------- | -------------------------------------------------------------- |
| `environment`      | argument | dev, preview, staging or production.                           |
| `--dir`            | option   | The folder holding the scope's ciphertext; default `.secrets`. |

## What it does

Reads the file names of the scope's ciphertext and the names every member declares. It decrypts nothing.

## What it prints

One warning per orphan name and where it sits, or that there is none.

## Exit codes

| Code | Means                                                                        |
| ---- | ---------------------------------------------------------------------------- |
| 0    | Always, orphans included: an orphan is a finding to clean up, not a failure. |
| 1    | Outside a proved CI job, or the scope's ciphertext is missing.               |

## Where it runs

Only in a CI job its GitHub OIDC token proves.

## Examples

```bash
stackra runway env orphans staging --dir .secrets
```
