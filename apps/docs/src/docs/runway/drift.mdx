Lists where each Cloudflare Worker's live settings differ from what runway.yaml renders.

```bash
stackra runway drift [environment] [--json]
```

| Argument or option | Kind     | Meaning                                       |
| ------------------ | -------- | --------------------------------------------- |
| `environment`      | argument | The runway environment; default `production`. |

## What it does

Read-only Cloudflare API GETs with `CLOUDFLARE_API_TOKEN_READ`, for each Worker member of
`targets.cloudflare-workers`. It never applies anything.

## What it prints

Each Worker setting that differs from the rendered config.

## Exit codes

| Code | Means                                                                                    |
| ---- | ---------------------------------------------------------------------------------------- |
| 0    | No Worker drifted.                                                                       |
| 1    | A Worker drifted (a finding: the nightly drift run fails), or the read token is missing. |
| 2    | Usage error.                                                                             |

## Where it runs

In CI, the nightly `runway-drift.yml` decrypts the read token from the sops scope `ci/deploy`. Locally only with that
token in the environment.

## Examples

```bash
stackra runway drift
stackra runway drift staging
```
