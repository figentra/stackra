---
title: "Reusable snippets"
description: "Write a passage once and include it on many pages."
icon: "recycle"
---

Files in `snippets/` are not pages of their own. Import them into a page:

```mdx
import VerifyFirst from "/snippets/verify-first.mdx";

<VerifyFirst />
```

Rendered:

import VerifyFirst from "/snippets/verify-first.mdx";

<VerifyFirst />
