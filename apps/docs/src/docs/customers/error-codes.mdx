Every Stackra tool that refuses names a code. Find the code on this page for what usually causes it and the usual
fix. The line the tool printed is always more specific (it names your class, file or key), so read it first; this page
explains the rule behind it. For failures that come before any code (installing, Node, the registry, Encore), see
[Troubleshooting](/customers/troubleshooting).

The same rows are in your terminal: `stackra explain <code>` prints a code's cause, fix and link to its section here
(`--json` for the data), and the local developer MCP serves it as its `explain` tool. Every gen finding ends with a
`docs:` line that links to its code's section.

## Gen

`stackra gen` reads your classes and writes everything under `.stackra/`. When something it reads breaks a rule, it
refuses: it prints every refusal of the run, writes nothing, and exits 1. Each refusal is two lines:

```text
src/modules/orders/models/order.model.ts:12:3 error shape_number_kind Order.total: a number field needs @Int or @Num
  fix: add @Int for whole numbers or @Num for decimals above the field
```

The parts are the file (with the line and column when gen knows them), `error` or `warning`, the code, the subject (a
class, `Class.field` or a key) and the message, then the fix. A **warning** prints the same way but never stops gen.
`stackra gen --check` runs the same checks without writing and also fails when a committed generated file is out of
date (`stackra check` reports that as the [`stale`](#check) rule).

The five **staged** codes (`action_risk_below_write`, `idempotency_missing`, `model_tenancy_migration_missing`,
`query_above_l1`, `step_up_missing`) print as warnings unless gen runs strict (`STACKRA_GEN_STRICT=1`); strict, they
refuse like every other code. Treat them as refusals. When a root Turborepo task runs gen, list the variable in its
`env` so it reaches gen (the [`gen-strict-env`](#check) rule).

### Files, classes and kinds

| Code                           | Cause                                                                                                                                                        | Fix                                                                                                                                                                    |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `two_declarations_in_file`     | A file exports more than one declaration.                                                                                                                    | Move each declaration to its own file; an enum's constant and its same-named type count as one.                                                                        |
| `kind_class_name`              | A class in a kind file (such as `order.model.ts`) is not named after the file.                                                                               | Rename the class to the name gen expects, or rename the file after the class.                                                                                          |
| `kind_suffix_mismatch`         | A class of one kind sits in a file with another kind's suffix.                                                                                               | Move it to a file with its own kind's suffix in its kind's folder, or extend the base of the suffix's kind.                                                            |
| `kind_unregistered_base`       | A class in a kind file extends no base gen knows.                                                                                                            | Extend the kind's base from its `@stackra` package, or move the class out of the kind file. Run `pnpm install` first: an uninstalled package makes every base unknown. |
| `kind_base_name_reserved`      | A model takes the name of a kind base (such as `Model`).                                                                                                     | Rename the model after the domain word it stands for.                                                                                                                  |
| `kind_path`                    | A command class sits outside its kind's `commands/` folder.                                                                                                  | Move it to the folder the message names.                                                                                                                               |
| `empty_module`                 | A module file states nothing gen cannot derive from its folder.                                                                                              | Delete the file: the folder is the module.                                                                                                                             |
| `event_base_abstract`          | A class extends `Event`, the abstract base of the event kinds.                                                                                               | Extend `DomainEvent`, `IntegrationEvent`, `WebhookEvent` or `AnalyticsEvent`.                                                                                          |
| `override_duplicate`           | Two classes in one member override the same base class.                                                                                                      | Keep one override per base and merge the other into it.                                                                                                                |
| `override_legacy_name`         | An override does not keep the plain name of the class it overrides.                                                                                          | Rename it to the base's name and import the base under an alias (`Base<Name>`).                                                                                        |
| `module_cycle`                 | Modules depend on each other in a cycle.                                                                                                                     | Move the shared part into one module, or into a third module both import, so dependencies point one way.                                                               |
| `sibling_not_exported`         | A class injects a class of another module that the module does not export.                                                                                   | Add it to `exports` of that module's `Module({ exports })`, or inject something the module exports.                                                                    |
| `token_not_a_class`            | A constructor parameter is not typed with a class.                                                                                                           | Type each injected parameter with the class or port to inject, or `Named<Port, "name">`.                                                                               |
| `partner_mismatch`             | A paired class (policy, connection) is typed against a partner with a different name, or against a type alias.                                               | Name the class after its partner, or pass the partner explicitly as the message says.                                                                                  |
| `partner_unresolved`           | A type argument names a class gen cannot import.                                                                                                             | Import the partner class by its own name from its package's public entry.                                                                                              |
| `port_key_mismatch`            | A port's written `~key` brand differs from the key gen derives.                                                                                              | Write the derived key the message shows, or delete the brand.                                                                                                          |
| `port_unbound`                 | A class injects a port that no driver binds in this member.                                                                                                  | Write a driver for the port, or add to `package.json` a package that ships one.                                                                                        |
| `app_definition_not_static`    | The `defineApp` argument in `stackra.config.ts` is not plain data.                                                                                           | Pass one object of literals and enum cases: no spread, call, shorthand or computed key.                                                                                |
| `shim_authored`                | A hand-written config file sits where gen writes its own (a tool config that does not import the generated one, a root declaration tsconfig, an `app.json`). | Import and extend the generated config, or delete the file so gen writes it.                                                                                           |
| `manifest_unshipped`           | The package's `files` in `package.json` leaves out `stackra.manifest.json`.                                                                                  | Add `stackra.manifest.json` to `files`.                                                                                                                                |
| `package_entities_modules`     | A package has models in more than one module.                                                                                                                | Keep a package's models in its one module.                                                                                                                             |
| `module_key_collision`         | A module of the member has the same key as a module of a package it hosts.                                                                                   | Rename the member's module (its folder and key).                                                                                                                       |
| `client_dependency_missing`    | A generated client imports an `@stackra` package the member does not declare.                                                                                | Add the package the message names to `dependencies`.                                                                                                                   |
| `schema_dependency_missing`    | A generated schema imports a package (such as `zod`) the member does not declare.                                                                            | Add the package the message names to `dependencies`.                                                                                                                   |
| `generated_dependency_missing` | The generated wiring needs a package the member does not declare, directly or through another undeclared package.                                            | Add every package the message lists to `dependencies`; one refusal lists them all as lines to paste.                                                                   |

### Shapes and fields

| Code                              | Cause                                                                                           | Fix                                                                                                                                  |
| --------------------------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `shape_unknown_type`              | A field's type is not one a schema can hold.                                                    | Use a shape type the message suggests (a primitive, an enum, a schema class, a brand).                                               |
| `shape_number_kind`               | A number field has neither `@Int` nor `@Num`, or both.                                          | Add `@Int` for whole numbers or `@Num` for decimals (`each: true` inside an array or map).                                           |
| `shape_decorator_type_mismatch`   | A rule decorator does not apply to the field's type.                                            | Remove the decorator, or change the field's type.                                                                                    |
| `shape_rule_not_constant`         | A rule decorator's arguments are not constants.                                                 | Use literals or literal-typed `const` values.                                                                                        |
| `shape_default_not_constant`      | A field default is computed.                                                                    | Use a literal, an enum case, a literal constant, `null`, `[]`, `{}`, `Duration.*` or `Money.of`; compute other values in `create()`. |
| `shape_default_member_unresolved` | A default names a member its owner does not have (often a renamed enum case).                   | Use a member that exists, or check the import.                                                                                       |
| `shape_hatch_reason_missing`      | `@Field(zod)` has no reason.                                                                    | Add a `// reason:` line above `@Field` saying why no type fits.                                                                      |
| `shape_hatch_local_binding`       | `@Field(zod)` uses a value declared in the same file, which the generated schema cannot import. | Write the zod inline, or move the value to an exported constant imported by a package or `#` path.                                   |
| `relation_decorator_missing`      | A relation field has no decorator naming its target model.                                      | Add `@ManyToOne`, `@OneToMany` or `@ManyToMany`, or type a model of another module as `Link<Target>`.                                |
| `data_class_unknown`              | `dataClass` names no data class gen can read.                                                   | Use a `DataClassification` value or a `DataClass({ key })` class.                                                                    |

### Identity and names

Identities (action and query keys, event wire names, permission keys, public id prefixes) are part of your API. Once
`stackra.manifest.json` is committed they are locked.

| Code                       | Cause                                                                                | Fix                                                                                      |
| -------------------------- | ------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------- |
| `identity_changed`         | A locked identity changed: a class, key, setting or settings group was renamed.      | Add `@Renamed("old")` to the class, or restore the old name.                             |
| `identity_collision`       | Two classes derive the same identity (key, integration key or report key).           | Rename one class, or give one a different written key or name.                           |
| `identity_invalid`         | An error class's name does not give a valid code.                                    | Name the class in PascalCase ending in `Error`.                                          |
| `identity_missing`         | An action, query, sequence or rule outcome has no written `key`.                     | Write the key the message shows, such as `Action({ key: "model.verb" })`.                |
| `integration_key_invalid`  | An integration's written key is not two snake_case parts joined by a dot.            | Write `group.name`, such as `connectors.stripe`, or leave it out to derive it.           |
| `integration_role_unknown` | An integration names a role that is not an Integration role.                         | Use one of the roles the message lists.                                                  |
| `event_name_prefixed`      | An event's written name starts with the module or member key, which gen adds itself. | Drop the prefix: the wire name is always `module.name.vN`.                               |
| `event_name_shape`         | An integration event's name is missing or is not `aggregate.verb` in snake_case.     | Write `IntegrationEvent({ name: "order.paid" })`; keep an old wire name with `@Renamed`. |
| `prefix_invalid`           | A public id prefix is not 2 to 6 lowercase letters.                                  | Write a prefix such as `HasPublicId("ord")`.                                             |
| `prefix_duplicate`         | Two models use the same public id prefix.                                            | Give one of them another prefix, or host only one of them.                               |
| `prefix_taken`             | The prefix is registered to another member in gen's prefix registry.                 | Pick a prefix the registry does not list.                                                |
| `effect_unknown`           | An effect tag is not one of the known tags.                                          | Use one of the tags the message lists.                                                   |
| `permission_unknown`       | An action or query uses a permission no Permissions class declares.                  | Add the static the message shows to the module's Permissions class.                      |

### Actions, queries and approvals

| Code                                | Cause                                                                                                                                                   | Fix                                                                                                                    |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `action_handle_signature`           | An action has no `handle`, its input is not a schema of this member, or its return type is not written as `Promise<Output>`.                            | Declare `handle(input)` with the member's input schema and an explicit `Promise` return type.                          |
| `listener_handle_signature`         | A listener's `handle` does not take an event class.                                                                                                     | Type the first parameter with the event class it reacts to, or `EventEnvelope` for a relay of every event.             |
| `action_risk_below_write`           | Staged. An action uses a permission below L2, but an action writes.                                                                                     | Raise the permission to `Permission.L2` (L3 for money, L4 for access, deletion or customer sends).                     |
| `query_above_l1`                    | Staged. A query's permission is above L1, but a query only reads.                                                                                       | Give it an L0 or L1 permission, make it an action, or write a `// reason:` on its `permission` for a deliberate floor. |
| `idempotency_missing`               | Staged. A client can call the action (an endpoint or a tool) but it declares no `idempotency`.                                                          | Write `idempotency: Idempotency.Optional`, `Required`, `Derived` or `Never`.                                           |
| `step_up_missing`                   | Staged. A high-risk action a user can call declares no `stepUp`.                                                                                        | Add `stepUp: AssuranceLevel.Aal2`.                                                                                     |
| `step_up_exemption_unlisted`        | An action declares a step-up exemption but is not a first-factor enrolment action.                                                                      | Declare `stepUp: AssuranceLevel.Aal2`.                                                                                 |
| `credentials_ignore_not_anonymous`  | `credentials: "ignore"` on an action whose actors are not exactly anonymous.                                                                            | Set `actors: [ActorKind.Anonymous]`, or remove `credentials`.                                                          |
| `action_cache`                      | An action declares `cache`; an action's answer is never cached.                                                                                         | Remove `cache`, or move the read into a query.                                                                         |
| `query_precondition`                | A query declares `preconditions`, which only actions run.                                                                                               | Refuse inside `handle`, or make it an action.                                                                          |
| `stream_output_mismatch`            | `stream: true` and a `ReadableStream` answer do not go together.                                                                                        | Declare both or neither.                                                                                               |
| `public_without_endpoint`           | Something is marked `public` but has no endpoint.                                                                                                       | Give it an endpoint, or drop `public: true`.                                                                           |
| `tool_reason_missing`               | An agent-tool choice (`tool: false` on a user action, `tool: true` on a risky one) has no reason; also printed for a code hatch file gen does not know. | Add a `// reason:` line above the `tool` option; move an unknown hatch's setting into `stackra.config.ts`.             |
| `intent_phrases_missing`            | `intent: true` but the language catalogue has no intent phrases for the action.                                                                         | Add the `actions.<key>.intents` list to the catalogue, or drop `intent: true`.                                         |
| `secret_output_kept`                | Warning. An action returns a field that reads as a secret, and the idempotency store keeps outputs for replays.                                         | Mark the field `@ShownOnce`, or declare `idempotency: Idempotency.Never`.                                              |
| `site_cache_reads_caller`           | A query cached per site reads the caller, so one caller's answer is served to everyone.                                                                 | Stop reading the caller, or cache per principal (the default) or per scope.                                            |
| `action_without_workflow`           | Warning. An action reaches past its module but starts no workflow, so a later failure cannot compensate.                                                | Move the cross-module work into a workflow started with `ctx.run`.                                                     |
| `workflow_without_action`           | A controller or listener starts a workflow directly.                                                                                                    | Call an action that starts the workflow, or set the workflow's `startOn` for an event.                                 |
| `approval_on_query`                 | A query declares approval; a query changes nothing.                                                                                                     | Remove `approval`, or make it an action.                                                                               |
| `approval_not_constant`             | The `approval` option is not constant.                                                                                                                  | Write `approval` as `true` or an object of constants and class references.                                             |
| `approval_actor_not_allowed`        | Approval is declared for an actor kind an approval may not gate.                                                                                        | Limit `actors` to users and agents, or remove `approval`.                                                              |
| `approval_credential_input`         | An action with approval takes a credential in its input, which a parked request would keep.                                                             | Take a connection id instead of the credential, or remove `approval`.                                                  |
| `approval_window_too_long`          | `expiresAfter` is above 30 days.                                                                                                                        | Write at most `"720h"`.                                                                                                |
| `approval_condition_dependency`     | An approval condition has constructor dependencies.                                                                                                     | Remove the constructor; the condition receives a limited settings reader.                                              |
| `approval_condition_reads_unmarked` | An approval condition reads a setting not marked for approval.                                                                                          | Mark the setting `@Setting({ approval: true })`, or read another key.                                                  |

### Endpoints, jobs and webhooks

| Code                          | Cause                                                                                           | Fix                                                                                                |
| ----------------------------- | ----------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `endpoint_collision`          | Two routes are on the same method and path.                                                     | Give one of them another key or `endpoint: { method, path }`.                                      |
| `endpoint_method_mismatch`    | A query is not on GET, an action is on GET, or a transition is not on PUT.                      | Use the method the message names, or change the kind.                                              |

| `cron_input_invalid`          | A cron job's `input` does not match the action's input schema.                                  | Write `input` as the message says.                                                                 |
| `cron_job_collision`          | Two cron actions map to the same Encore cron job id.                                            | Give one of them another written key.                                                              |
| `queue_unprovisioned`         | A job runs on a queue the root `runway.yaml` does not declare for an environment.               | Add the queue under `environments.<env>.queues` with its visibility timeout and dead-letter queue. |
| `egress_invalid`              | An integration's `baseUrl` is not an https origin.                                              | Write an https URL; a per-region host uses a `{field}` of the credential set.                      |
| `webhook_event_id_undeclared` | A webhook receiver names no event id, so the inbox would treat every event as one.              | Name `webhooks.eventId` or a signature id header.                                                  |
| `webhook_event_unpaired`      | A hosted package's webhook event names an integration or connection its manifest does not list. | Regenerate that package's manifest, or declare the event beside its integration.                   |
| `webhook_route_duplicate`     | Two classes handle the same provider webhook type.                                              | Keep one class for the type.                                                                       |

### Data, migrations and search

| Code                              | Cause                                                                                        | Fix                                                                                                                                |
| --------------------------------- | -------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `model_tenancy_missing`           | A model is neither tenant-owned nor declared global, so its table has no row-level security. | Add `BelongsToTenant` to the model (and `t.belongsToTenant()` to its migration), or extend `Model.global(...)` for a global table. |

| `document_number_unsequenced`     | A document number names no declared sequence.                                                | Declare it with `Sequence({ key })`, or name an existing one.                                                                      |
| `credential_field_not_encrypted`  | A field classified as a credential is not encrypted.                                         | Add the field to `HasEncryptedFields`.                                                                                             |
| `encrypted_field_unknown`         | `HasEncryptedFields` names a field the model does not declare.                               | Declare the field, or remove it from the list.                                                                                     |
| `encrypted_field_unclassified`    | An encrypted field has no `@Classified` class.                                               | Add `@Classified(DataClassification.<Class>)`.                                                                                     |
| `encrypted_native_write`          | A raw or native write skips the unit of work, so encrypted fields would be stored in clear.  | Write through the repository or `CrudService`.                                                                                     |
| `encrypted_lookup_unknown`        | `lookup` names a field that is not encrypted.                                                | Add it to the encrypted fields, or remove it from `lookup`.                                                                        |
| `encrypted_lookup_undeclared`     | A looked-up field has no blind-index column on the model.                                    | Declare the index field the message names, and its column in a migration.                                                          |
| `encrypted_lookup_not_indexed`    | No index leads with the blind-index column, so lookups scan the table.                       | Add the `@Index` the message shows, and the index to a migration.                                                                  |
| `encrypted_lookup_subject`        | `lookup` is combined with a subject key, which would still match an erased subject.          | Drop `lookup`, or seal under the scope instead.                                                                                    |
| `searchable_columns_drift`        | `@Searchable` and the latest `t.searchable` migration describe different fields.             | Follow the expand, reindex, contract steps the fix prints.                                                                         |
| `searchable_semantic_ai_never`    | Semantic search would embed a field whose data class forbids AI.                             | Drop the field from the facet's text, or drop `semantic: true`.                                                                    |
| `sort_not_indexed`                | A resource table sorts by a field no index leads with.                                       | Add the `@Index` the message shows, or drop the sort.                                                                              |
| `filter_not_indexed`              | A resource table filters on a field no index leads with.                                     | Add the `@Index` the message shows, or drop the filter.                                                                            |
| `entitlement_unknown`             | Something names an entitlement no member or hosted package declares.                         | Import an `Entitlement` class that exists, or add the package that declares it.                                                    |
| `entitlement_counts_unknown`      | An entitlement counts a model this member does not have.                                     | Count a model this member or a hosted package declares.                                                                            |
| `addition_target_missing`         | A model addition names no base model, or one the base's released manifest lacks.             | Extend `ModelAddition(Base)` with a released model, or build against a base version that has it.                                   |
| `addition_base_source`            | A model addition imports its base from source.                                               | Import the base from the base product's released client package.                                                                   |
| `addition_key_collision`          | Two additions nest fields on one base model under the same key.                              | Keep one addition per base model in a module.                                                                                      |

### Resources, reports, commands and UI

| Code                           | Cause                                                                             | Fix                                                                               |
| ------------------------------ | --------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| `resource_duplicate`           | Two resources (or two hosted packages) declare the same resource.                 | Keep one resource per model and area, or depend on one of the packages.           |

## Check

`stackra check` runs the quality gate's phases in order: config, format, spelling, secrets, structure, docs, lint,
hooks, gen, typecheck, catalogues and spec (`--with-tests`, or `stackra verify`, adds the tests). `stackra validate`
runs the config, structure, docs, catalogues and spec phases. `--only` and `--skip` pick phases, `--fix` applies what
can be fixed, and `--format json` prints the findings as data. Each finding
names its location, its tool and rule, and the message (`[fixable]` when `stackra check --fix` can fix it):

```text
services/orders/src/modules/orders/actions/pay-order.action.ts  repo-checks/imports  import "../../../shared/money" climbs two or more folders; use the member's # alias (ADR 0233)
```

### Phase findings

| Code             | Cause                                                          | Fix                                                                    |
| ---------------- | -------------------------------------------------------------- | ---------------------------------------------------------------------- |
| `format`         | A file is not formatted.                                       | Run `pnpm format` (or `stackra check --fix`).                          |

| `exit`           | A tool exited non-zero without a finding the phase could read. | Run the tool alone to see its output; the message holds its last line. |
| `crash`          | A phase threw before it could report.                          | Read the message; it is usually a missing install or build.            |

Some phases pass the tool's own rule names through: **lint** shows the oxlint rule (such as
`oxlint/eslint(no-debugger)`; Stackra's own lint rules are named `stackra`), **secrets** shows the gitleaks rule, **typecheck** shows the TypeScript code (`TS2345`), and
**gen** shows the [gen code](#gen) above.

## Runway

Runway checks the runway files and runs deploys, promotions and rollbacks.

### Runway issue codes

These come from the root `runway.yaml` checks. `stackra runway validate` prints placement issues as
`runway.yaml: <message> (<code>)`.

| Code                     | Cause                                                                                 | Fix                                                      |
| ------------------------ | ------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| `member_unplaced`        | A service is in no group of an environment's topology, and there is no default group. | Add it to a group, or set `default`.                     |
| `member_placed_twice`    | A service is in two groups of one environment.                                        | Keep it in one.                                          |
| `unknown_member`         | A group lists a name that is not a service member.                                    | Fix the name, or remove it.                              |
| `unknown_default_group`  | `default` names a group that is not declared.                                         | Declare the group, or fix the name.                      |
| `isolate_unknown_member` | `isolate` names something that is not a service member.                               | Fix the name, or remove it.                              |
| `host_collision`         | Two surfaces use the same host in one environment.                                    | Give each surface its own host.                          |
| `duplicate_port`         | Two dev ports land on the same port once lanes are added.                             | Change one port, the `portStep` or the repository index. |
| `port_out_of_range`      | A dev port lands above 65535.                                                         | Lower the port, the `portStep` or the repository index.  |
| `unknown_region`         | An environment deploys to a region `regions` does not declare.                        | Declare the region, or fix the key.                      |
| `cloud_unconfigured`     | A region runs on a cloud whose `providers` section is missing.                        | Add the provider section.                                |
| `unknown_account`        | A region names a cloud account the provider section does not have.                    | Add the account, or fix the name.                        |
| `zone_owner_conflict`    | Two root runways claim the same DNS zone.                                             | Set `owner: true` in exactly one.                        |

### Runway errors

| Code                      | Cause                                                                                                                                                                                    | Fix                                                                                    |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| `RunwayInvalidError`      | A runway file breaks its schema; the message lists every invalid path.                                                                                                                   | Fix each path; run `stackra runway validate`.                                          |
| `RunwayUnresolvedError`   | A value cannot be resolved where it is read: no dev facts (`stackra dev` has not run), a missing environment, no earlier release, or a deploy-time value the environment does not carry. | Do what the message says: run `stackra dev`, add the environment, or set the variable. |
| `RunwayLockedError`       | Another deploy, promotion or rollback is running in the environment.                                                                                                                     | Wait for it to end, then run again.                                                    |
| `RunwayDeployFailedError` | A target did not verify after a deploy, promotion or rollback; later targets were not touched.                                                                                           | Read the provider detail in the message, fix the target, and run again.                |
| `RunwaySmokeFailedError`  | The smoke step failed or had no driver for a subject, so promotion is blocked.                                                                                                           | Fix the failing subjects the message names, then promote again.                        |
