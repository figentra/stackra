How to run one leader election.

| ------ | ----------- |
| `readonly method?: ElectionMethod;` | The method to use; by default Web Locks, else a BroadcastChannel, else memory, whichever exists first. |
| `readonly heartbeat?: Duration;` | How often a BroadcastChannel leader announces itself; the others take over after three missed beats. Ignored by the other methods. Default `Duration.seconds(1)`. |

| `whenLeader: () => Promise<void>;` | Resolves once this participant leads, at once when it already does. · Throws Error (as a rejection) when the participant resigns first. |

### `electLeader`

Function · declared in `src/core/functions/elect-leader.function.ts`

```ts
function electLeader(name: string, options?: ElectLeaderOptions): LeaderElection;
```

Joins the named election.

**Throws** RangeError when `name` is empty.

**Example**

```ts
const election = electLeader("query.queue");
election.isLeader.subscribe((leads) => (leads ? queue.start() : queue.stop()));
window.addEventListener("pagehide", () => election.resign());
```

Runs `task` once this tab holds the named lock, then releases it, whether the task resolves or throws.

**Throws** whatever `task` throws, after the lock is released.

**Example**

```ts
const token = await withTabLock("identity.refresh", () => refreshToken());
```
