**Example**

```ts

  super();
  this.locks = locks;
}

await this.locks.with(keys, Duration.seconds(5), async () => { ... });
```

| Member | Description |
| ------ | ----------- |
| `readonly owner: string;` | The owner every lease of this process carries. |
| `constructor(driver: LockDriver, clock: Clock);` | `driver`: the store config `locking.driver` picks. · `clock`: the time source of the wait. |
| `with<T>(keys: string \| readonly string[], ttl: Duration, work: (lease: LockLease) => Promise<T>): Promise<T>;` | Runs `work` holding every key of `keys`, and gives back its result. Waits at most `ttl` for keys another lease holds (a holder that died frees them within it); the lease is renewed every third of `ttl` while `work` runs, and released when it ends, however it ends. · Throws LockUnavailableError when a key stayed held for the whole wait; `work` did not run. · Throws RangeError when `ttl` is zero. |
| `tryWith(keys: string \| readonly string[], ttl: Duration, work: (lease: LockLease) => Promise<void>): Promise<boolean>;` | Runs `work` holding every key of `keys` only when none is held now, without waiting; `true` when it ran. On a schedule this is "one runner per tick": every instance tries, one runs. · Throws RangeError when `ttl` is zero. |
