### `PricePoint`

Class · declared in `src/core/values/price-point.value.ts`

```ts
class PricePoint {
    readonly step: number;
    readonly ending: number;
    readonly currency: CurrencyCode;
    static ofMinor(step: number, ending: number, currency: string): PricePoint;
    apply(price: Money, rounding?: Rounding): Money;
}
```

The price points `k × step + ending` (k = 0, 1, 2 …) of one currency.

**Example**

```ts
const charm = PricePoint.ofMinor(100, 99, "USD"); // 0.99, 1.99, 2.99 …
charm.apply(Money.of("12.34", "USD")).toDecimal(); // "12.99"
charm.apply(Money.of("12.34", "USD"), Rounding.HalfEven).toDecimal(); // "11.99", the nearest point
```

| Member | Description |
| ------ | ----------- |
| `readonly step: number;` | The distance between two points in minor units: a positive safe integer (100 is one dollar in USD). |
| `readonly ending: number;` | The minor units every point ends on: an integer from 0 to `step - 1` (99 gives x.99 in USD). |
| `readonly currency: CurrencyCode;` | The currency `step` and `ending` are counted in. |
| `static ofMinor(step: number, ending: number, currency: string): PricePoint;` | The points `k × step + ending` in `currency`. · `step`: minor units between two points; a positive safe integer. · `ending`: minor units each point ends on; an integer from 0 to `step - 1`. · `currency`: an ISO 4217 code; a plain string is checked here. · Throws RangeError when `step` is not a positive safe integer, `ending` is outside 0 to `step - 1`, or `currency` is not a code with minor units. |
| `apply(price: Money, rounding?: Rounding): Money;` | `price` moved onto a point. `Up` gives the smallest point at or above it, `Down` the largest at or below it, and `HalfUp` or `HalfEven` the nearest, a tie going up or to the point with an even `k`. A price at or below the first point (`ending`) becomes the first point in every mode; zero stays zero, so a free item is not given a price. · `price`: a non-negative amount in this point's currency. · `rounding`: which neighbouring point to take; `Up` by default, so a rounded price never undercuts the list. · Returns a new `Money` on a point, or `price` itself when it is zero. · Throws RangeError when `price` is negative or in another currency, or the point is beyond the safe-integer limit. |
