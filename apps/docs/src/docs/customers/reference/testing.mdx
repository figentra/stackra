### `Fake`

Class · declared in `src/core/fake.fake.ts`

```ts
abstract class Fake {
    static of<T extends object>(port: abstract new () => T): FakeConstructor<T>;
    record(name: string, value: unknown): void;
    calls(name: string): readonly unknown[];
}
```

Extend `Fake.of(Port)` for a fake of a port, or `Fake` for a double with no port. A subclass implements the methods
its tests need and calls `this.record(name, value)` in each; every other method of the port is a `vi.fn()` spy.
Statics such as `static with(...)` go on the subclass. TypeScript still asks for every abstract method of the port:
one left to its spy is written `declare count: Port["count"];`, which emits nothing.

**Example**

```ts
class MembersFake extends Fake.of(LoyaltyMembers) {
  async isMember(id: MemberId): Promise<boolean> {
    this.record("isMember", id);
    return true;
  }
}
```

| Member | Description |
| ------ | ----------- |
| `static of<T extends object>(port: abstract new () => T): FakeConstructor<T>;` | A concrete class of `port`. Its instances are the port (`instanceof` holds, so a container override accepts them), record calls, and answer every method no class in the chain implements with a spy named `<Port>.<method>`, created on first read and kept for the instance's life. · `port`: the abstract class to fake; its constructor takes no argument. · Returns the class to extend, named `<Port>Fake`. |
| `record(name: string, value: unknown): void;` | Records one call of `name` with its first argument, in order. · `name`: the method that was called. · `value`: its first argument. |
| `calls(name: string): readonly unknown[];` | The values recorded for `name`, oldest first; empty when it was never recorded. · `name`: the method to read. |
