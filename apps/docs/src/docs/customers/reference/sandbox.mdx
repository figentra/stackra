Runs code steps in a pool of processes.

**Example**

```ts
pool.open({ size: settings.sandboxProcesses, graceMs: settings.sandboxGraceMs });
const { output, codeMs } = await pool.run({ code, input, limits, allowedOrigins, reference: ctx.stepKey });
await pool.close();
```

| Member | Description |
| ------ | ----------- |
| `constructor(proxy: SandboxFetchProxy);` | `proxy`: the egress the host binds for `SandboxFetchProxy`. |
| `open(options: SandboxPoolOptions): void;` | Starts `options.size` processes. · Throws RangeError when the size is not a whole number from 1, the grace is negative or the start-up deadline is not more than 0. · Throws TypeError when the pool is already open. |
| `run(request: SandboxRequest): Promise<SandboxResult>;` | Runs `request` in the next free process. · Throws TypeError when the pool is not open or is closing. · Throws SandboxCodeFailedError and SandboxLimitExceededError as `Sandbox.run` does; a process that dies mid-run is `SandboxCodeFailedError`, one the watchdog kills is `SandboxLimitExceededError` with limit `time`, and one that does not load Pyodide within the start-up deadline is `SandboxCodeFailedError`. |
| `close(): Promise<void>;` | Refuses the queued runs, kills every process and waits for them to exit. |
