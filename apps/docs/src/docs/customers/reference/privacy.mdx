Reach for this when a person asks for their data or asks to be forgotten (PDPL, GDPR): modules declare their personal data with the PersonalData kind; this package exports it to a signed zip and erases it through a workflow that crypto-shreds, deletes or anonymises, honours legal holds and issues receipts.
