
The props a registry's consumer hands the component it draws. `size`, `color` and `strokeWidth` are the drawing;
the rest is what `Icon` relies on for accessibility, the tone colour and the right-to-left mirror, so a component
that is meant to be decorative, labelled, tinted or mirrored must spread them onto its root element. Lucide icons
do; a custom SVG component that ignores them stays visible to assistive technology and cannot be mirrored.

| Member | Description |
| ------ | ----------- |
| `readonly size?: number \| string;` | The width and height in pixels, from the icon size: `sm` 16, `md` 20, `lg` 24. |
| `readonly color?: string;` | The stroke colour, a resolved colour; native only, the web icon draws in `currentColor`. |
| `readonly strokeWidth?: number \| string;` | The stroke width on the icon's 24-unit grid; Lucide draws 2 when it is left out. |
| `readonly className?: string;` | Web: the class the holder styles the icon with; a component must put it on its root element. |
| `readonly style?: object;` | The tone colour (web) and the mirror transform, as the platform's own style object; it must reach the root. |
| `readonly "aria-hidden"?: boolean;` | Web: set for a decorative icon so screen readers skip it. |
| `readonly "aria-label"?: string;` | Web: the accessible name of a labelled icon. |
| `readonly role?: "img";` | Web and native: `img` on a labelled icon. |
| `readonly accessible?: boolean;` | Native: whether the icon is an accessibility element; false for a decorative one. |
| `readonly accessibilityLabel?: string;` | Native: the accessible name of a labelled icon. |
| `readonly accessibilityElementsHidden?: boolean;` | Native, iOS: hides a decorative icon from VoiceOver. |
| `readonly importantForAccessibility?: "no-hide-descendants";` | Native, Android: hides a decorative icon from TalkBack. |
