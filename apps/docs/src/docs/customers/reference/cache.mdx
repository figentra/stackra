### `Cache`

Class · declared in `src/contracts/ports/cache.port.ts`

```ts
abstract class Cache extends Port {
    readonly "~key": "cache.Cache";
    abstract get<T>(key: CacheKey): Promise<T | undefined>;
    abstract put<T>(key: CacheKey, value: T, ttl: Duration, options?: CachePutOptions): Promise<void>;
    abstract remember<T>(key: CacheKey, ttl: Duration, load: () => T | Promise<T>, options?: CacheRememberOptions): Promise<T>;
    abstract forget(key: CacheKey): Promise<void>;
    abstract forgetTag(tag: CacheKey): Promise<void>;
    flush(): Promise<void>;
}
```

Holds values for a while.

**Example**

```ts
constructor(cache: Cache) { ... }

view(id: PublicId<"prd">, locale: Locale): Promise<ProductView> {
  return this.cache.remember(CacheKey.of(Product, id, locale), Duration.minutes(10), () => this.load(id, locale));
}

ctx.afterCommit(() => this.cache.forget(CacheKey.of(Product, product.id))); // every locale's view
ctx.afterCommit(() => this.cache.forgetTag(CacheKey.of(Category, category.id))); // every entry tagged with it
```

| Member | Description |
| ------ | ----------- |
| `readonly "~key": "cache.Cache";` | Type-only port key, so `DriverName<Cache>` narrows to this port's drivers. |
| `abstract get<T>(key: CacheKey): Promise<T \| undefined>;` | The value stored under `key`, or `undefined` when none is stored or it has expired. |
| `abstract put<T>(key: CacheKey, value: T, ttl: Duration, options?: CachePutOptions): Promise<void>;` | Stores `value` under `key` for `ttl`, tagged with `options.tags`; a zero `ttl` stores nothing. A load in flight for `key` is not stored. |
| `abstract remember<T>(key: CacheKey, ttl: Duration, load: () => T \| Promise<T>, options?: CacheRememberOptions): Promise<T>;` | The value stored under `key`, or the result of `load`, stored for `ttl`. Concurrent calls for one key share one `load`. A rejected `load` stores nothing and rejects every caller that shared it. With `options.stale`, an entry past its lifetime but inside the window is answered at once while one background load replaces it; with `options.lock`, one load runs across the instances that share the store. |
| `abstract forget(key: CacheKey): Promise<void>;` | Drops `key` and every key it covers: `CacheKey.of(Product, id)` covers `CacheKey.of(Product, id, locale)`. A load in flight for a covered key still answers its callers but is not stored. |
| `abstract forgetTag(tag: CacheKey): Promise<void>;` | Drops every entry of the current namespace stored with `tag` among its tags. Tags match exactly. A load in flight that carries the tag still answers its callers but is not stored. |
| `flush(): Promise<void>;` | Drops every entry of the current namespace (`cache:clear`). A load in flight still answers its callers but is not stored. A driver that cannot enumerate its entries leaves this default, which rejects. |

| `constructor(config: CacheConfig, namespace: CacheNamespace, clock: Clock, lock: CacheLock, metrics: CacheMetrics);` | `config`: the binding name of the KV namespace (`workers.binding`). · `namespace`: the prefix of every key; the shared namespace unless config `cache.namespace` selects another. · `clock`: the time source of expiry. · `lock`: guards a `remember(..., { lock: true })` fill across isolates; config `cache.lock` picks it. · `metrics`: where hits, misses, loads and evictions go; config `cache.metrics` picks it. · Throws TypeError when the Worker has no KV namespace bound under that name. |
