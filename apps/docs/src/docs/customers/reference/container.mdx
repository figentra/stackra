
The DI container. Built by `Container.create` (the runtime's `createApp`, or the testing module), then read by
class.

**Example**

```ts
const container = await Container.create([wiring], { overrides: new Map([[LoyaltyKitConfig, config]]) });
container.get(LoyaltyService).quote(member, 100, 10_000);
```

| Member | Description |
| ------ | ----------- |
| `static create(wirings: readonly Wiring[], options?: ContainerOptions): Promise<Container>;` | Boots a container: merges `wirings` (dependencies first, the member last), loads the selected driver of every port, builds every singleton binding of the booted modules and the classes their module files export, then runs each Explorer's `onApplicationBootstrap()` once. · Throws UnresolvedPortError when a port has no driver to load and nothing overrides or replaces it. · Throws Error on a dependency cycle, or when a binding needs a class nothing binds. |
| `get<T extends object>(token: AnyClass<T>): T;` | The instance for a class, or for a named instance of a port. · Throws UnresolvedPortError for a port with no driver. · Throws Error for a class nothing binds, a cycle, or a `Lifetime.Request` binding read outside `forRequest()`. |
| `get<P extends Port, N extends string>(token: NamedToken<P, N>): Named<P, N>;` | The instance of `P` that config names `N`. |
| `getAll<T extends object>(base: AnyClass<T>): T[];` | Every class the booted modules bind or export that extends `base`, built (or read from cache) in wiring order: dependencies first, the host last. This is the multi-binding: the module that owns an extension point declares an abstract base, and each module that contributes to it binds a subclass. `base` itself is never in the list. · Throws Error when a contribution has `Lifetime.Request` and this is not a `forRequest()` container. |
| `has(token: Token): boolean;` | Whether the container binds `token`: an override, a loaded driver, a config class, a binding or a built-in. |
| `bindings(): readonly ContainerBindingEntry[];` | What the container can build, as names, for tooling such as the devtools tab: each booted binding and exported class, each loaded driver and named instance, and each config class, with its scope, lifetime and the class built. Read-only, and never an instance: nothing is built to answer it. |
| `forRequest(): Container;` | A container for one request: it shares the singletons and keeps its own `Lifetime.Request` instances. |
| `instances(): readonly object[];` | The singletons the root container has built, in build order. |
| `close(): Promise<void>;` | Calls `onApplicationShutdown()` on every instance this container built that has one, last built first, and forgets them. Overrides belong to whoever passed them and are left alone. |
