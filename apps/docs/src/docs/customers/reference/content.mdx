
Keeps the revisions of records.

**Example**

```ts
const draft = await revisions.draft(ctx.scope, "catalogue.product", product.id, snapshot);
await revisions.schedule("catalogue.product", product.id, draft.number, blackFriday, "black_friday");
await revisions.publishDue(clock.now()); // from the tenant schedule
```

| Member | Description |
| ------ | ----------- |
| `draft(scope: ScopeRef, model: string, recordId: string, data: Readonly<Record<string, unknown>>): Promise<Revision>;` | Adds the next numbered draft of `recordId` of `model`, holding `data`. |
| `publish(model: string, recordId: string, number: number, at: Date): Promise<Revision>;` | Makes revision `number` the current one from `at`; a scheduled revision is no longer scheduled. · Throws NotFoundError when the record has no such revision. |
| `current(model: string, recordId: string): Promise<Revision \| null>;` | The revision published last, which readers see; null while none is published. |
| `schedule(model: string, recordId: string, number: number, at: Date, campaign?: string \| null): Promise<Revision>;` | Schedules revision `number` to go live at `at`, in `campaign` when given. · Throws NotFoundError when the record has no such revision. |
| `unschedule(campaign: string): Promise<Revision[]>;` | Clears the schedule of every revision of `campaign` not yet published; returns them. |
| `publishDue(now: Date): Promise<Revision[]>;` | Publishes every scheduled revision whose time has come by `now`, at its scheduled time; returns them. |
| `rollback(model: string, recordId: string, at: Date): Promise<Revision>;` | Makes the revision published before the current one current again, from `at`. · Throws NotFoundError when fewer than two revisions were ever published. |
