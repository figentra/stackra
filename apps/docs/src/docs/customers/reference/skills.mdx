### `parseAgentDocument`

Function · declared in `src/core/functions/parse-agent-document.function.ts`

```ts
function parseAgentDocument<K extends AgentDocumentKind>(kind: K, text: string, source: string): Extract<AgentDocument, {
    kind: K;
}>;
```

The parsed document of `kind`.

| Parameter | Description |
| --------- | ----------- |
| `kind` | which kind of document `text` is. |
| `text` | the whole Markdown file. |
| `source` | its file path; the name is derived from it (`skills/<name>/SKILL.md`, `rules/<name>.md`). |

**Throws** AgentDocumentInvalidError naming every invalid path: no frontmatter, a missing or empty required key, an
        unknown key, a name that is not kebab-case or differs from the path, a hook event no assistant has.

**Example**

```ts
const rule = parseAgentDocument("rule", text, "rules/naming-and-casing.md");
rule.always; // true
```


The parsed documents under `root`.

| Parameter | Description |
| --------- | ----------- |
| `root` | a folder holding `skills/`, `rules/`, `subagents/`, `commands/` and `hooks/`, any of which may be missing; defaults to this package's `assets/`. |
