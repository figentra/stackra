### `LibraryOptions`

```ts
interface LibraryOptions {
    decorators?: boolean;
    external?: (string | RegExp)[];
    optionalRequires?: readonly string[];
}
```

Options accepted by `library`.

| Member | Description |
| ------ | ----------- |
| `decorators?: boolean;` | Transpile TypeScript experimental (legacy) decorators in the built output. No `design:*` metadata is emitted (ADR-0005): Encore's esbuild bundler cannot emit it, so no code may depend on it. Mechanism (tsdown 0.23 / rolldown): oxc does this natively through rolldown's `transform.decorator` — `legacy` is `experimentalDecorators`. The flags are set explicitly rather than left to tsconfig discovery so a package that passes a custom tsconfig still builds correctly. Pair with `@stackra/typescript-config/decorators`; rolldown then sees the same flags twice and reports an equal-value CONFIGURATION_FIELD_CONFLICT, which is filtered below. |
| `external?: (string \| RegExp)[];` | Mark packages external even if they are dependencies (rare: peer-provided runtimes). |
| `optionalRequires?: readonly string[];` | Optional peers a native entry loads lazily with `require("x")` inside a try, so an app without the peer still runs (`expo-haptics`). rolldown turns each into its `__require` shim, which Metro never resolves, so the guard rewrites a listed name's shimmed call back to a literal `require`, which Metro sees and bundles; any other shimmed or literal `require` in a chunk still fails the build (STA-1722). |

### `library`

Function · declared in `src/functions/library.function.ts`

```ts
function library(entries?: Record<string, string>, options?: LibraryOptions): LibraryConfig;
```

Build configuration for a TypeScript library using tsdown + rolldown.

Produces ESM output with declaration files, sourcemaps, clean dist, and tree-shaking enabled.
By default, builds a single `src/index.ts` barrel; pass `entries` to build subpath exports.

| Parameter | Description |
| --------- | ----------- |
| `entries` | Map of output names to source entry points. Default: `{ index: "src/index.ts" }`. Example: `{ index: "src/index.ts", react: "src/react/index.ts" }`. |
| `options` | Build options (decorator support, external packages). |

**Returns** the tsdown configuration object, ready to be the default export of `tsdown.config.ts`.

**Example**

```ts
export default library(); // src/index.ts → dist/index.mjs + index.d.mts
```

**Example**

```ts
export default library({ index: "src/index.ts", react: "src/react/index.ts" }); // subpath exports
```

**Example**

```ts
export default library(undefined, { decorators: true }); // DI tier (legacy decorators, no metadata)
```
