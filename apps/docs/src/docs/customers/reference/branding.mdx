| Member | Description |
| ------ | ----------- |
| `constructor(settings: SettingsReader, store: SettingValueStore, disk: FileSystem);` | `settings`: reads `BrandingSettings`. · `store`: the settings value store `settings` reads. · `disk`: the one `FileSystem` disk media stores on. |
| `profile(locale: Locale, target?: SettingTarget): Promise<BrandProfile>;` | The resolved profile in `locale`, at `target` (the running scope session's node when left out). It never throws on a stored value: a malformed one reads as unset and a low-contrast colour is skipped. |
| `bytes(image: BrandImage): Promise<Uint8Array \| null>;` | The original bytes of `image` (PNG or JPEG, at most the bucket's 512 KiB), read from the disk, for a surface that embeds the image (a printed document); `null` when the file has gone since `profile` resolved it.
