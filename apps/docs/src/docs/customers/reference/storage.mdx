
One storage area.

**Example**

```ts

```

| Member | Description |
| ------ | ----------- |
| `get: (key: string) => Json \| undefined;` | The value under `key` as JSON, or `undefined` when absent or expired. |
| `set: (key: string, value: unknown, options?: StorageWriteOptions) => void;` | Stores `value` under `key` as JSON. · Throws TypeError when `value` has no JSON form (`undefined`, a function). · Throws RangeError when `options.ttl` is not a duration. |
| `has: (key: string) => boolean;` | Whether a live value is stored under `key`. |
| `delete: (key: string) => void;` | Removes the value under `key`; nothing happens when there is none. |
| `keys: () => string[];` | The keys of every live value, in insertion order. |
| `clear: () => void;` | Removes every value of the area. |
| `read: <T extends object>(type: AnyClass<T>) => T;` | The stored value of a shape class, decoded and with its defaults applied; the shape's defaults when nothing is stored or what is stored no longer fits the shape. · Throws TypeError when gen registered no key or no schema for `type`. · Throws ZodError when nothing fits and the shape has a field without a default. |
| `write: <T extends object>(type: AnyClass<T>, value: T, options?: StorageWriteOptions) => void;` | Checks `value` against the schema of `type` and stores it under the key gen registered for `type`. · Throws TypeError when gen registered no key or no schema for `type`. · Throws ZodError when `value` does not fit the shape; nothing is stored then. |
