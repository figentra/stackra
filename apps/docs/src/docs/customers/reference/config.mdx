    constructor(config: AwsSecretsManagerConfig);

Reads secrets from AWS Secrets Manager.

**Example**

```ts
const store = new AwsSecretsManagerSecretStoreDriver(buildConfig(AwsSecretsManagerConfig, { values }));
await store.load();
```

| Member | Description |
| ------ | ----------- |
| `constructor(config: AwsSecretsManagerConfig);` | `config`: the region and the secret ids. |
| `load(): Promise<void>;` | Reads every configured secret, replacing what an earlier load read. · Throws Error when the region or the ids are missing, or a secret cannot be read (ids only, no value). |
| `get(name: string): string \| undefined;` | See `SecretStore.get`: the loaded value of `name`, or `undefined` when the store has none. · Throws Error before the first `load`. |
