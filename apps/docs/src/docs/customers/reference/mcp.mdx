### `execWithSecrets`

```ts
function execWithSecrets(argv: readonly string[], options?: McpExecOptions & {
    readonly cwd?: string;
}): Promise<number>;
```

Runs `argv` with its secrets and resolves with the exit code.

| Parameter | Description |
| --------- | ----------- |
| `argv` | the program and arguments written after `stackra mcp exec --`. |
| `options` | the figentra/secrets clone and the working directory. |

**Throws** Error when `argv` is empty, or rejects when the program (or `sops`) cannot start.

**Example**

```ts
process.exitCode = await execWithSecrets(["npx", "-y", "mcp-remote@0.14.3", url, "--header", "x-token:$TOKEN"]);
```

| --------- | ----------- |
| `file` | the path of a `.mcp.yaml`. |

**Throws** McpConfigInvalidError when the file cannot be read, is not YAML, or breaks the shape or rules.

**Example**

```ts

```

### `syncMcpConfig`

Function · declared in `src/node/functions/sync-mcp-config.function.ts`

```ts
function syncMcpConfig(root?: string): {
    readonly file: string;
    readonly changed: boolean;
};
```

Renders `.mcp.json` from `.mcp.yaml` in `root`.

| Parameter | Description |
| --------- | ----------- |
| `root` | the repository root; defaults to the working directory. |

**Returns** the written file and whether its text changed.

**Throws** McpConfigInvalidError when `.mcp.yaml` is missing or invalid; `.mcp.json` is then left as it was.

**Example**

```ts
const { changed } = syncMcpConfig(); // run by `pnpm install` through `prepare`
```
