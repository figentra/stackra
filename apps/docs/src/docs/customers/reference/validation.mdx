Interface · declared in `src/core/types/identifier-format.type.ts`

```ts
interface IdentifierFormat {
    readonly pattern: string;
    readonly check?: IdentifierCheck;
    readonly canonical?: string;
}
```

One identifier's shape, from market-pack data.

**Example**

```ts
const trn: IdentifierFormat = { pattern: "^100\\d{12}$" };
const iban: IdentifierFormat = { pattern: "^SA\\d{2}[0-9A-Z]{20}$", check: IdentifierCheck.Mod97 };

```

| Member | Description |
| ------ | ----------- |
| `readonly pattern: string;` | The regular expression source the normalised value must match. |
| `readonly check?: IdentifierCheck;` | The check-digit or structure algorithm the value must also pass. |
| `readonly canonical?: string;` | The stored form, written from the pattern's groups (`$1 $2`; `$1` to `$9`); the normalised value itself when left out. A group that did not match is left out with the text just before it, so `$1-$2` writes `12345` for a five-digit ZIP and `12345-6789` for ZIP+4. The check runs on the normalised value, before this rewrite. |
