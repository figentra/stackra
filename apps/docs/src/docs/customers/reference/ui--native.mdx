### `Component`

Class · declared in `src/native/component/component.ts`

```ts
abstract class Component<P extends object = object> {
    readonly props: Readonly<P>;
    readonly state: ReactComponent<P>["state"];
    readonly context: ReactComponent<P>["context"];
    readonly setState: ReactComponent<P>["setState"];
    readonly forceUpdate: ReactComponent<P>["forceUpdate"];
    abstract render(): ReactNode;
}
```

The base of a native class component.

**Example**

```ts
export class Greeting extends Component<GreetingProps> {
  render() {
    return <Text>{this.props.name}</Text>;
  }
}
```

| Member | Description |
| ------ | ----------- |
| `readonly props: Readonly<P>;` | The props the host passed; a component never writes them. |
| `readonly state: ReactComponent<P>["state"];` | React's state slot; a class component's fields are its state once compiled. |
| `readonly context: ReactComponent<P>["context"];` | React's context slot; a component reads a context through a hook field. |
| `readonly setState: ReactComponent<P>["setState"];` | React's setter; a component writes a field instead. |
| `readonly forceUpdate: ReactComponent<P>["forceUpdate"];` | React's re-render; never needed, since a field write re-renders. |
| `abstract render(): ReactNode;` | What the component draws. |
