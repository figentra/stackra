| `quote(member: MemberId, requested: number, total: MoneyAmount, rates: RedemptionRates): Promise<RedemptionQuote>;` | Largest redemption allowed for `requested` points against `total`: never more than the balance, never more than `maxRedeemPercent` of the total, converted at `pointValueMinor`.
