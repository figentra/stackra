```ts
abstract class IncomingShare extends Port {
    readonly "~key": "native_share.IncomingShare";
    abstract pending(): Promise<readonly SharedItem[]>;
    abstract read(item: SharedItem): Promise<Blob | null>;
    abstract clear(): Promise<void>;
    abstract subscribe(listener: () => void): () => void;
}
```

The share inbox of a native app.

**Example**

```ts
const share = useContainer().get(IncomingShare);
for (const item of await share.pending()) if (item.kind === "file") await uploader.upload(await share.read(item), null);
await share.clear();
```

| Member | Description |
| ------ | ----------- |
| `readonly "~key": "native_share.IncomingShare";` | Type-only port key, so `DriverName<IncomingShare>` narrows to this port's drivers. |
| `abstract pending(): Promise<readonly SharedItem[]>;` | The shared items not yet cleared, limited to what the configuration accepts. |
| `abstract read(item: SharedItem): Promise<Blob \| null>;` | The bytes of a shared file; `null` for a text or a link, a file that is gone, or one over `maxBytes`. |
| `abstract clear(): Promise<void>;` | Forgets every shared item once the app has handled them. |
| `abstract subscribe(listener: () => void): () => void;` | Calls `listener` whenever a new share may have arrived; returns the unsubscribe function. |
