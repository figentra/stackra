```ts
interface JobResult<O> {
    readonly id: PublicId<"job">;
    readonly outcome: JobOutcome;
    readonly attempts: number;
    readonly output: O | undefined;
    readonly error: unknown;
    readonly runs: readonly JobRun[];
}
```

The outcome of one job run to its end in a test.

| Member | Description |
| ------ | ----------- |
| `readonly id: PublicId<"job">;` | The job's id. |
| `readonly outcome: JobOutcome;` | How its last attempt ended: never `retried`. |
| `readonly attempts: number;` | The number of attempts made. |
| `readonly output: O \| undefined;` | The action's output when the job is done; `undefined` otherwise. |
| `readonly error: unknown;` | What the last attempt threw when it failed; `undefined` when done. |
| `readonly runs: readonly JobRun[];` | Every attempt, oldest first. |

### `drainQueue`

Function · declared in `src/testing/functions/drain-queue.function.ts`

```ts
function drainQueue(queue?: string): Promise<readonly JobRun[]>;
```

Drains the current testing app's queue.

**Returns** every attempt made, in order.

**Throws** Error before any testing app compiled.

**Example**

```ts
await run(SendMessageAction, input, { as, idempotencyKey: "k1" });
await drainQueue(); // runs DeliverMessageAction
```

Runs `type` with `input` as a job until its last attempt.

| Parameter | Description |
| --------- | ----------- |
| `options` | the caller, scope or Idempotency-Key, as `QueueService.push` takes them. |

**Throws** Error before any testing app compiled, or when a unique job of the same scope already waits or runs.

**Example**

```ts

expect(job).toDeadLetter({ attempts: 6 });
```
