### `CspAdditions`

Interface · declared in `src/core/types/csp-additions.type.ts`

```ts
interface CspAdditions {
    readonly connect?: readonly string[];
    readonly nonce?: string;
    readonly path?: string;
    readonly frameAncestors?: readonly string[];
    readonly consent?: readonly string[];
}
```

The per-response additions of `contentSecurityPolicy`.

| Member | Description |
| ------ | ----------- |
| `readonly connect?: readonly string[];` | `connect-src` sources from the environment (the API gateway, realtime, error reporting); a URL counts by origin. |
| `readonly nonce?: string;` | The request's nonce from `createNonce`; without one, scripts and `<style>` elements load from the origin only. |
| `readonly path?: string;` | The request's URL path (`url.pathname`); it picks the `frameAncestors` entry. Without one, no page may frame. |
| `readonly frameAncestors?: readonly string[];` | The framers a resolver found for this request, on a `"request"` path only; none (an unknown session) is `'none'`. |
| `readonly consent?: readonly string[];` | The viewer's granted consent categories (`ConsentCategory` codes); without them only `necessary` scripts load. |


The policy of one response.

**Throws** TypeError when the nonce is not base64, an added source is not one host or scheme source, or a framer is
        not `self` or one origin.
