<Info>
  This page is for working on Stackra itself. To build **your own app** with Stackra, start at
  [Create your first app](/customers/create): `stackra create` makes it in an empty folder.
</Info>

<Steps>
  <Step title="Install the toolchain">
    `mise.toml` pins Node, pnpm, gitleaks, sops, age, uv and Maestro. With [mise](https://mise.jdx.dev) installed:

    ```bash
    mise install
    ```

  </Step>
  <Step title="Install dependencies">
    ```bash
    pnpm install
    ```

    `prepare` installs the lefthook git hooks.

  </Step>
  <Step title="Run an app">
    ```bash
    pnpm console
    pnpm docs      # http://localhost:3333
    pnpm mobile    # iOS simulator (needs Xcode)
    ```
  </Step>
  <Step title="Add a service">
    ```bash
    stackra new service demo --area app --summary "Demo."   # pnpm new service demo ... is its alias
    pnpm install
    cd services/demo && stackra gen && stackra test
    ```
  </Step>
  <Step title="Verify before you push">
    ```bash
    pnpm verify
    ```
  </Step>
</Steps>
