# "by figentra_" — the endorsement Stackra uses

Copied verbatim from the Figentra brand kit (`../figentra/marks/`), which owns these files. Do not edit
here: rebuild the Figentra kit, then this kit.

- **Who uses it:** Stackra, a light sub-brand, leads with its own name and is signed "by figentra_" · "من فيجنترا_"
  (Brand System, Lockups). Inside a lockup the signature is already drawn: use `logos/svg/stackra-endorsed-*`.
  Use these standalone files only where the name is set separately, such as a footer or a package registry page.
- **Never** "powered by figentra_" — that badge is for a third party's product on Figentra OS.
- **Colours:** letters in `--muted`, the bar in `--cursor` (amber). The bar is the only amber on a Stackra
  surface. Stackra "never takes the amber cursor": nothing follows the stackra name.
- **Files:** `by-figentra.{horizontal,compact}.{light,dark}.{en,ar}.svg` (outlined, clear space inside the
  artboard) and `@2x.png`. Light files go on paper or white, dark files on ink.
- **Minimum size and clear space:** see `../figentra/marks/marks.json` (figentra_ at 20px minimum).
