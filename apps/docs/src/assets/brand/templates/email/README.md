# Stackra — email

Generated by `scripts/build.mjs`. Table-based HTML email, 600px wide, every colour an inline hex from the
light theme (email clients ignore custom properties and external CSS), and a web-safe fallback after each brand
face: Geist → Segoe UI → Helvetica → Arial; IBM Plex Sans Arabic → Tahoma → Arial; Geist Mono → Menlo → Consolas.

| Template | Files |
| --- | --- |
| Newsletter (package notes) | `newsletter-{en,ar}.html` |
| Welcome | `welcome-{en,ar}.html` |
| Receipt | `receipt-{en,ar}.html` — every value a placeholder: Stackra's licensing and pricing are not defined |
| Password reset | `reset-{en,ar}.html` — the docs account is an assumption to confirm |
| Signature | `../stationery/email-signature-{en,ar}.html` |

- The button is ink with paper text (18:1): Stackra has no accent, so the primary action is the neutral one.
- Links are underlined; colour alone never marks them.
- Host `logos/png/stackra-endorsed-*-light-h64.png` at a public URL and replace the relative `src` before sending.
- Every `[bracketed]` value is listed in `../PLACEHOLDERS.md`.
