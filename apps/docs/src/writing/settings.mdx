---
title: "Site settings"
description: "What each part of docs.json controls."
icon: "settings"
---

| Key                                        | Controls                                                                             |
| ------------------------------------------ | ------------------------------------------------------------------------------------ |
| `theme`, `colors`, `appearance`, `styling` | Look: layout theme, brand colours, light/dark default, eyebrows and code-block style |
| `logo`, `favicon`                          | Brand assets in `assets/logo/` and `assets/favicon.svg`                              |
| `icons.library`                            | The icon set for `icon:` in frontmatter and components (`lucide`)                    |
| `navigation`                               | Tabs, groups and pages                                                               |
| `search`, `seo`                            | The search placeholder, which pages are indexed, and meta tags                       |
| `contextual`                               | The page menu: copy as Markdown, view source, open in ChatGPT or Claude              |
| `errors`                                   | The 404 page                                                                         |

Add `navbar`, `footer.socials` and `integrations` (analytics) once the public repository, social accounts and analytics properties exist. The full schema is at [mintlify.com/docs.json](https://mintlify.com/docs.json).
