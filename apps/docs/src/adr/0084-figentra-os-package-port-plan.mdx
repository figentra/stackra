## Context

Figentra OS (`@figentra-os/*`, 55 packages in the same ten categories) is Stackra's ancestor. The owner decided, package by package, what to port. Some packages port as they are, some are adapted or redesigned, some start fresh, some are skipped, and some become Pro. Each port still goes through the gate (spec, review), and the code is relicensed to MIT as it is ported ([0024](/adr/0024-mit-license-with-exclusions)). This page is the plan. Each package's design ADR is written when it lands ([0018](/adr/0018-framework-design-record)).

## Decision

1. **Conventions every ported package meets**:
   - A file-contract docblock on every file and a docblock on every export ([0007](/adr/0007-source-documentation-standard)).
   - One export per file, `#` subpath imports, and no `any`, non-null assertions or enums ([0006](/adr/0006-naming-exports-and-imports)).
   - No `Reflect` metadata. Code that calls `Reflect.defineMetadata` (kbd, pwa) switches to the container's `WeakMap` metadata store. `reflect-metadata` stays rejected ([0011](/adr/0011-rejected-and-deferred-technologies)).
   - The diagnostics catalogue is kept, and its prefix becomes `STK`.
   - Devtools tabs (through `@stackra/devtools-kit`) only where a package needs one.
   - Driver packages follow the instance-module pattern and ship a conformance suite ([0076](/adr/0076-every-package-runs-saas-on-prem-and-air-gapped)).
   - No `encore.dev` import ([0078](/adr/0078-messaging-layer-eight-packages)). Names follow [0083](/adr/0083-npm-scopes-and-cli-names).
2. **The plan.** Actions: port as-is, port + adapt, redesign, fresh, skip, Pro.

## Consequences

- The ported set is large, and most of it is mechanical, so it can be delegated ([0066](/adr/0066-delegation-to-opencode-by-routing-matrix)). Adapt, redesign and fresh rows need a spec each.
- Category folders are created with their first package ([0028](/adr/0028-package-categories-appear-with-first-package)). `@stackra/brand` already lives in `experience`, while Figentra OS keeps brand in `cross-cutting`. Which folder it ends in is settled when the Figentra `BrandService` is merged into it.
- A row changes by a new ADR or an amendment to this one.

## Enforcement

Existing: `FORBIDDEN_DEPENDENCIES` (`reflect-metadata`) in `tools/scripts/validate-repository.mjs`, and `boundaries.jsonc` (`encore.dev`). Planned: an oxlint rule banning `Reflect.defineMetadata` and `Reflect.getMetadata`, a docblock check, and a test that every diagnostic code starts with `STK`.
