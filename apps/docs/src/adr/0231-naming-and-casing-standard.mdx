## Context

Casing was decided piece by piece: files in ADR 0006, code shapes in 0128, permission keys in 0132, event names in 0141, machine codes in 0137.
On 2026-10-20 the owner asked for one table that says every casing and where it applies. The forms below are the owner's recorded answers
(`stackra-decisions-2026-10-19.md`, Gap-analysis answers, L930): permission keys `<module>.<resource>.<action>` (A10), event names
`<module-key>.<aggregate>.<verb>.v<n>` (C27 with the module key), and machine codes snake_case.

## Decision

1. The table below is the proposed standard. Each row says where the casing applies. A name that no row covers needs a decision first.

| Thing                                                                                         | Casing                                                                         | Example                                                 | Where it is set                   |
| --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ | ------------------------------------------------------- | --------------------------------- |
| Files and folders under `src/`, and document and rule file names                              | kebab-case                                                                     | `token.class.ts`, `class-provider.interface.ts`         | 0006 rule 1                       |
| Package names                                                                                 | `@stackra/<name>`, kebab-case name                                             | `@stackra/vite-plugin`                                  | AGENTS.md package table           |
| TypeScript types, interfaces, classes, enum objects and React components                      | PascalCase                                                                     | `Token`, `ErrorBoundary`, `Scope`                       | 0128                              |
| Functions, methods, variables and parameters                                                  | camelCase; functions are verb-first                                            | `formatLabel`, `defaultRetryPolicy`                     | proposal section 2                |
| Constants: fixed tables and primitives fixed at build time                                    | SCREAMING_SNAKE, `as const`                                                    | `MAX_PAGE_SIZE`                                         | proposal section 2                |
| Constants: computed or configuration-shaped values                                            | camelCase                                                                      | `defaultRetryPolicy`                                    | proposal section 2                |
| DI tokens (`defineToken` values)                                                              | SCREAMING_SNAKE, no `_TOKEN` suffix                                            | `LOGGER`, in `logger.token.ts`                          | proposal section 2; 0145          |
| Machine codes: error categories and codes, refusal codes, event reasons, STK and domain codes | snake_case                                                                     | `not_found`, `entitlement_required`, `step_up_required` | 0137; 0140                        |
| Event names                                                                                   | `<module-key>.<aggregate>.<verb>.v<n>`, lowercase, one segment per part        | `billing.invoice.paid.v1`, `identity.user.created.v1`   | 0141 (C27 with the module key)    |
| Permission keys                                                                               | `<module>.<resource>.<action>`, lowercase                                      | `billing.invoice.refund`                                | 0132 (A10)                        |
| Module keys                                                                                   | lowercase dotted namespace                                                     | `identity.users`                                        | 0131                              |
| Database tables and columns                                                                   | snake_case                                                                     | `tenant_id`, `created_at`                               | proposal; to be confirmed         |
| URL path segments                                                                             | kebab-case; path parameters in `:camelCase`                                    | `/users/:userId/archive`                                | http-conventions rule             |
| HTTP headers                                                                                  | Title-Case, as sent                                                            | `Idempotency-Key`, `Stackra-Version`                    | http-conventions rule; 0136; 0118 |
| Public ids                                                                                    | lowercase `prefix_` plus 26 characters                                         | `user_01jh4q...`                                        | 0135                              |
| i18n keys                                                                                     | dotted; each segment snake_case; a machine code's key is derived from the code | `errors.not_found`                                      | 0162 (C36)                        |
| Environment variables and secret names                                                        | SCREAMING*SNAKE; the config override form is `STACKRA*<PKG>\_\_<PATH>`         | `STRIPE_SECRET_KEY`, `STACKRA_PAYMENTS__TIMEOUT_MS`     | 0146                              |
| Branch names                                                                                  | Linear form `figentra/sta-<n>-<slug>`, kebab-case slug                         | `figentra/sta-175-adr-wave-1-part-4`                    | AGENTS.md Linear rule             |
| Commit types and scopes                                                                       | lowercase conventional commits                                                 | `docs(adr): ...`                                        | commitlint                        |

2. **Existing conventions are kept.** ADR 0006 rule 1 (kebab-case files) and rule 2 (one exported declaration per file, with a kind suffix)
   stand. ADR 0128 stands. The `STACKRA_` env prefix (0146) and public-id prefixes (0135) stand.
3. **Open for the owner.** The full table is being agreed (acronym casing such as `ID` and `URL`, abbreviations, ids, file names). Design-token
   casing is also open: the brand package keeps its current names until the owner decides.
4. **Derived forms.** Where the owner named a thing but not a segment form, the form follows the machine-code rule (snake_case words inside a
   segment) and is listed as derived: i18n segments, database multi-word names.

## Consequences

- While Proposed, the rows marked with a source (0132, 0141, 0137, 0146, 0135, 0006, 0128) hold through those ADRs, and the rest is a draft.
- The always-on rule is not added until this ADR is accepted, so agents do not read a draft as binding.
- The secret example in AGENTS.md (`secret("StripeSecretKey")`, PascalCase) contradicts the SCREAMING_SNAKE row. It is fixed with the rule,
  in `.agents/rules/secrets.md`, after this ADR is accepted.

## Enforcement

planned — the oxlint `unicorn/filename-case` rule (kebab-case files, from the code-conventions proposal), the house lint rules of
[0129](/adr/0129-house-lint-plugin-and-coding-standard) for code shapes, and the validator checks for machine codes, event names and
permission keys, once the table is accepted.

## Alternatives

- One rule per ADR, as before: superseded by the owner's request for one table, once this table is accepted.
- SCREAMING_SNAKE for env and secret names only in Infisical, PascalCase in code: rejected, the owner set SCREAMING_SNAKE for all of them.
