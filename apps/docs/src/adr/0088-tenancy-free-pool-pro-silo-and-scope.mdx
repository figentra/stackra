## Context

[0045](/adr/0045-tenancy-package-pool-default-silo-on-demand) put pool tenancy, silo-on-demand and an `ltree` scope tree from day one into one free package. The open-core split ([0077](/adr/0077-open-core-free-and-pro-lists)) moves the scale features to Pro. The Figentra OS tenancy package also depends on the router, which a server-side package must not.

## Decision

1. **`@stackra/tenancy` is the one tenancy package.** Products and services use it; none implements isolation itself.
2. **Free: pool tenancy.** Every tenant-owned table has a `tenant_id` column, and row-level security is both `ENABLE`d and `FORCE`d on it. The package provides `withTenant` and an isolation test kit.
3. **The connection resolver is a free contract.** The pool resolver is free. **DB-per-tenant and move-tenant are a Pro driver** behind that contract.
4. **No schema-per-tenant.**
5. **The scope tree is Pro**, `@stackra-pro/scope`, and plugs into tenancy and `check()` ([0087](/adr/0087-identity-and-iam-are-driver-packages)). Free tenancy has no scope dependency.
6. **No router dependency.**
7. **Isolation is enforced at two layers**, the MikroORM scoped entity and the database policy, and **every tenant-owned table has a cross-tenant isolation test**, written with the kit.

## Consequences

- Free users get complete pool isolation. Silo and hierarchy are paid features.
- Academorix needs the scope tree from day one, so it would consume `@stackra-pro/scope` under an internal licence. This is open and awaits owner confirmation.
- The resolver contract must be designed for the Pro silo driver without it being present in this repository.

## Enforcement

Planned: a validator check that a migration creating a table with `tenant_id` also enables and forces RLS, and the per-table isolation test of decision 7, run on real Postgres. Nothing is implemented yet.
