## Context

[0011](/adr/0011-rejected-and-deferred-technologies) is the one table of rejected and deferred technologies. Since it
was written, waves 1 to 3 added or changed rows in separate ADRs: the Encore row ([0124](/adr/0124-encore-is-the-generated-runtime-target)),
the runtime schema engine ([0110](/adr/0110-experience-is-the-sdui-service-at-l2), [0154](/adr/0154-tenant-code-runs-only-in-a-sandboxed-code-step)),
the delegation row ([0193](/adr/0193-agents-and-model-policy)), and others. A reader had to read sixteen ADRs to learn one
row. The owner's answers also added rows that the table never held (Better Auth, Storybook, GraphQL and others).

## Decision

1. **One table.** The table below replaces the 0011 table. Do not introduce anything in the **Not introduced** column. If a
   task seems to need one, stop and route to the owner. Rejected means no. Deferred means not yet, and the trigger names when.
   A row changes only by a new ADR.
2. **Rows changed.**
   - The Encore row is the hand-written form only: `encore.dev` and `~encore/*` in service members are rejected, and Encore is the
     generated target in `.stackra/encore` ([0091](/adr/0091-generated-encore-app-in-stackra-folder), [0124](/adr/0124-encore-is-the-generated-runtime-target)).
   - The delegation row is removed. Agents run by tier under [0193](/adr/0193-agents-and-model-policy).
   - The AI gateway row is reworded. An LLM proxy gateway in front of model providers stays rejected. One MCP gateway in the
     ai service is allowed ([0155](/adr/0155-queries-are-mcp-tools-and-all-ai-code-is-free)).
   - The search row: OpenSearch is built on a measured trigger ([0221](/adr/0221-search-postgres-hybrid-elasticsuite-parity-arabic-and-operations)).
   - The authorization row: the OpenFGA and OPA adapters come later, behind the policy decision point ([0208](/adr/0208-iam-model-scope-tree-roles-conditions-deny-delegation-and-permission-names)).
   - The shared component row: the replacement is the `@stackra/ui` contract ([0165](/adr/0165-web-client-stack-ui-contract-form-adapters-and-no-nextjs)).
   - The observability row points to [0184](/adr/0184-telemetry-opentelemetry-otlp-slis-heartbeats-and-log-retention).
   - The runtime schema engine row adds the allowed forms that later ADRs record: tenant content types ([0226](/adr/0226-content-tenant-defined-types-at-runtime-and-headless-delivery)),
     tenant automations ([0153](/adr/0153-automations-run-as-principals-and-every-package-exposes-building-blocks)), and pricing blocks with no expressions ([0219](/adr/0219-the-merchant-account-chain-and-registered-price-models)).
3. **Rows added.** Better Auth, change-data-capture, XState, Storybook, GraphQL, hand-written gRPC, the Kafka/NATS/Redpanda bus
   drivers, and the deferred platform items: a vector store, a graph database, an OLAP engine, sharding, a second non-TypeScript
   runtime. Active-active across regions is rejected ([0186](/adr/0186-backups-and-disaster-recovery)).

## Consequences

- A proposal that touches one of these rows starts with a new ADR, not a pull request.
- Product-specific rejections (billing vendors, wallet design and similar) are not carried here; a product repository records its own.
- The Temporal driver stays as the Pro driver ([0151](/adr/0151-workflow-engine-is-a-port-with-native-and-temporal-drivers)); this table does not list it.

## Enforcement

- `FORBIDDEN_DEPENDENCIES` in `tools/scripts/validate-repository.mjs` fails a member that lists `eslint`, `prettier`, `jest`,
  `@nestjs/core`, `@nestjs/common`, `reflect-metadata`, `prisma`, `@prisma/client`, `drizzle-orm`, `express`, `fastify`, `typeorm` or `knex`.
- `packages/tooling/oxlint/src/boundaries.jsonc` bans `encore.dev` in packages.
- planned — extend `FORBIDDEN_DEPENDENCIES` with `next`, `better-auth`, `xstate`, `@storybook/*` and `graphql`, the rows this table adds.
- The `architecture-guardian` agent reads this page.

## Alternatives

- Leave the scattered row changes in their own ADRs and keep 0011 as it is. Rejected, because a reader would need sixteen ADRs to learn one row.
