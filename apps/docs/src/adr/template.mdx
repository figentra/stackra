Copy the block below into `NNNN-short-title.mdx`, add the page to `adr/index.mdx` and to `docs.json`.
Number from the highest existing ADR plus one. Never cite an ADR by a number from another repository.

## Status vocabulary

| Status             | Meaning                                                                        |
| ------------------ | ------------------------------------------------------------------------------ |
| Proposed           | Written, not yet agreed. Nothing may rely on it.                               |
| Accepted           | In force. Edited only to fix typos and to add or correct the Enforcement line. |
| Deferred           | Decided not to do it now. A Revival trigger is mandatory.                      |
| Rejected           | Decided against. A Revival trigger says what would change that.                |
| Superseded by NNNN | Replaced. The page stays, points forward, and the replacement points back.     |

Supersession happens in the same commit: the new ADR lists `Supersedes: NNNN`, the old ADR's status becomes
`Superseded by NNNN`, and the index row changes. A decision is never silently reversed.

## The template

```mdx
---
title: "NNNN — Title"
description: "Accepted · YYYY-MM-DD"
---

## Context

What forces the decision. Facts, constraints, the alternatives that were weighed. Two to six sentences.

## Decision

The rule, stated so a reviewer can say yes or no to a diff. Numbered or bulleted.

## Consequences

What gets easier, what gets harder, what is now someone's chore.

## Enforcement

The check that fails when the rule is broken (script, lint rule, hook, CI step), named by path.
Write `planned — <mechanism>` when nothing checks it yet. A rule with no check is a comment, and the page says so.

## Revival trigger

Only for Deferred and Rejected: the observable event that reopens the question.

## Supersedes and sources

`Supersedes: none` or `NNNN`. Then the origin documents (repository and path), informational only.
```
