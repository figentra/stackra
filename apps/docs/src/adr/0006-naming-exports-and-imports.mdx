## Context

File names, how many things a file exports, how barrels look and how modules name each other are decided on the first
file or re-argued on the twentieth. Four earlier decisions covered these separately. They are one convention, and it is
frozen before packages are created in bulk, because a codemod over many packages costs far more than agreeing now.

## Decision

1. **Kebab-case for every file and directory under `src/`.** No PascalCase, camelCase or underscores.
2. **One exported declaration per file**, named for it, with a kind suffix where the kind is not a plain function:
   `token.class.ts`, `scope.enum.ts`, `class-provider.interface.ts`, `payment.error.ts`. Barrels are exempt.
3. **Barrels re-export and nothing else.** `index.ts` is the only barrel name; it names every symbol
   (`export type { Token } from "./token.class"`), never `export *`, so the public surface is readable without compiling.
4. **Relative specifiers carry no extension and no trailing `/index`.** Exempt: package specifiers, non-code assets
   (`.css`, `.svg`, `.json`), generated output, raw Node `.mjs` and `.cjs` scripts under `tools/`, and `packages/tooling/*`
   (loaded by plain Node, which needs full specifiers).
5. **Climbing imports use package subpath imports.** A member with a `src/` tree declares `imports` in `package.json`
   (`#core`, `#application/*`, ...). A relative specifier may stay in its folder or descend; it never climbs with `../`.
   The `imports` map is generated by a script, never hand-written.
6. **A helper used by a second file moves to `utils/<name>.util.ts`.** A single-use private helper stays where it is used.
7. **Conventions change by ADR only.** No package-local exceptions.

## Consequences

- A file's name tells the reader what it exports; a rename is a move.
- Wildcard barrels are not available, so adding a symbol is a visible diff in the barrel.
- Subpath imports need a bundler and Metro that resolve `package.json` `imports`; native builds are verified before the first native entry ships.

## Enforcement

- `typescript/consistent-type-imports` in the base oxlint preset (off only in the decorators preset, see [0005](/adr/0005-di-container-and-legacy-decorators)).
- Planned: a validator check for kebab-case names, one export per file and barrel shape; an import-specifier check (port basalt `tools/scripts/import-style.mjs`); an `imports` map drift check against the generator.
