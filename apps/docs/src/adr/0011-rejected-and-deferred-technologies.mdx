## Context

Assistants and new contributors helpfully add well-known tools. Each one adds a second way to do something that already
has one, and each costs a migration to remove. The decisions against them are scattered across earlier repositories as
prose. This page is the one table. Each row says what is not introduced, what to use instead, and what event reopens it.

## Decision

Do not introduce anything in the **Not introduced** column. If a task seems to need one, stop and route to the
`architecture-guardian` agent. Rejected means no for the foreseeable future. Deferred means not yet, and the trigger
names when. A row changes only by a new ADR that supersedes this page.

## Consequences

- A proposal that touches one of these rows starts with a new ADR, not a pull request.
- Product-specific rejections (billing vendors, wallet design and similar) are not carried here; a product repository records its own.

## Enforcement

- `FORBIDDEN_DEPENDENCIES` in `tools/scripts/validate-repository.mjs` fails a member that lists `eslint`, `prettier`, `jest`, `@nestjs/core`, `@nestjs/common`, `reflect-metadata`, `prisma`, `@prisma/client`, `drizzle-orm`, `express`, `fastify`, `typeorm` or `knex`.
- `packages/tooling/oxlint/src/boundaries.jsonc` bans `encore.dev` in packages.
- Planned: extend the list with `encore.dev` for members other than a future service runtime, and with the other rows that name a package, after this table is reviewed.
- The `architecture-guardian` agent reads this page.
