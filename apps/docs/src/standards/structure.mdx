## Package entries

Core `.` is always present. An entry is exported once its folder holds a file, and its barrel is generated, never authored (ADR 0294 decision 15). `pnpm new package` adds the optional entries only with `--entries`.

| Entry       | Scaffolded | Holds                                                                            | Source       |
| ----------- | ---------- | -------------------------------------------------------------------------------- | ------------ |
| `contracts` | always     | the leaf: `ports/`, `enums/` and `types/`; imports nothing else from the package | ADR 0294 d15 |
| `node`      | always     | the module folder: the root module and the module groups                         | ADR 0294 d15 |
| `react`     | on request | web renderers in `react/<name>/`                                                 | ADR 0294 d15 |
| `native`    | on request | native renderers in `native/<name>/`                                             | ADR 0294 d15 |
| `testing`   | always     | `fakes/` and `matchers/` for consumers' tests                                    | ADR 0294 d15 |

Exception: `@stackra/testing` alone also has `e2e` and `contract` (ADR 0269 d6). No other package does.

## Member root (programming model v3)

Every member authors `stackra.config.ts` and one root module, `src/<name>.module.ts` (`src/node/<name>.module.ts` in a package), and never `src/main.ts` or an entry barrel (ADR 0294 R12, 0295). Exempt: the docs app (Mintlify) and the `tier:config` presets.

Root module: `src/<name>.module.ts`, test `<name>.module.int.test.ts`, ADR 0090.

React hooks: `use-<name>.ts` beside their component, test `use-<name>.test.ts` (unit), ADR 0129. Extension hooks are the only `hooks/` files.

Static files: `assets/<kind>/` at the package root (`public`, `lang`, `templates`, `stubs`, `data`), ADR 0234. static files shipped with a module; the word resource is reserved for @Resource.

## Banned folders

| Folder         | Why                                                                 | Source   |
| -------------- | ------------------------------------------------------------------- | -------- |
| `controllers`  | raw endpoints live in raw/ only; actions are the unit               | ADR 0130 |
| `dtos`         | Zod schemas replace DTO classes                                     | ADR 0095 |

## Test tiers

| Tier       | File infix       | Holds                                            | Source   |
| ---------- | ---------------- | ------------------------------------------------ | -------- |
| `unit`     | `.test`          | fast, no external services                       | ADR 0182 |
| `int`      | `.int.test`      | needs a real database or container               | ADR 0182 |
| `contract` | `.contract.test` | checks a declared contract, such as the manifest | ADR 0182 |
| `load`     | `.load.test`     | k6 load tests, run weekly against staging        | ADR 0182 |
| `e2e`      | `.e2e.test`      | runs a whole app                                 | ADR 0022 |

Every test file sits directly in a `__tests__/` folder beside its subject (ADR 0022). `.spec.*` is not used.
