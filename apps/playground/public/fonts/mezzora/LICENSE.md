# Fonts

Rubik, Cairo, Geist, Geist Mono and IBM Plex Sans Arabic are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org; full text in `OFL-Geist.txt` and `OFL-IBMPlexSansArabic.txt`, the same licence for
Rubik and Cairo). The files are unmodified WOFF2 files served by Google Fonts, copied from the Academorix deck
assets and the Figentra and Vellum kits so the kit renders and outlines offline. Rubik and Cairo are variable
fonts: one file per script covers every weight.
