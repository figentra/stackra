---
title: "Quickstart"
description: "From a clean machine to a running console and docs site."
icon: "rocket"
---

<Steps>
  <Step title="Install the toolchain">
    `mise.toml` pins Node, pnpm, gitleaks, the Infisical CLI, uv and Maestro. With [mise](https://mise.jdx.dev) installed:

    ```bash
    mise install
    ```

  </Step>
  <Step title="Install dependencies">
    ```bash
    pnpm install
    ```

    `prepare` installs the lefthook git hooks.

  </Step>
  <Step title="Run an app">
    ```bash
    pnpm console
    pnpm docs      # http://localhost:3333
    pnpm mobile    # iOS simulator (needs Xcode)
    ```
  </Step>
  <Step title="Add a service">
    ```bash
    stackra new service demo --area app --summary "Demo."   # pnpm new service demo ... is its alias
    pnpm install
    cd services/demo && stackra gen && stackra test
    ```
  </Step>
  <Step title="Verify before you push">
    ```bash
    pnpm verify
    ```
  </Step>
</Steps>
